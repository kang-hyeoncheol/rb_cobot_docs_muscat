조그로 로봇 움직이기 ​

조그(Jog)는 버튼을 누르고 있는 동안만 로봇을 조금씩 움직이는 기능입니다. 티칭 포인트를 잡거나 로봇의 현재 위치를 미세하게 조정할 때 가장 먼저 쓰게 됩니다.

이 문서에서는 동작 화면에서 다음을 해 봅니다. 세 실습은 서로 이어지지 않으므로 순서와 관계없이 하나만 골라 시작할 수 있습니다.

  • 관절(Joint) 조그로 관절을 하나씩 돌려 보기
  • 직교(Global) 조그로 TCP를 직선·회전 이동시키기
  • 속도 비율과 긴급 정지 위치 확인하기

시작하기 전에 ​

실제 로봇을 조작할 때

  • 로봇 주변에 사람과 장애물이 없는지 먼저 확인하세요.
  • 긴급 정지 버튼의 위치를 확인하고, 언제든 누를 수 있는 상태에서 조작하세요.
  • 처음에는 화면 아래의 속도 비율을 낮게 두고 시작하세요.

조그 방식 ​

동작 화면 오른쪽 위의 탭에서 조그 방식을 고릅니다.

탭움직이는 대상기준
Joint관절 하나(J0~J6)의 각도각 관절 축
GlobalTCP의 위치(X·Y·Z)와 자세(RX·RY·RZ), 팔꿈치 자세(AA)로봇 베이스 좌표계
LocalTCP의 위치와 자세현재 툴(TCP) 좌표계
UserTCP의 위치와 자세사용자 좌표계

용어

  • TCP(Tool Center Point): 로봇 끝에 붙은 툴의 기준점입니다.
  • AA(Arm Angle): 7축 로봇이 같은 TCP 위치·자세에서도 팔꿈치를 어디에 둘지 나타내는 값입니다.

직접 해 보기 ​

각 실습은 로봇이 처음 자세인 상태에서 시작합니다. 실습 창의 다시 하기는 해당 실습을 처음 자세로 되돌려 다시 시작합니다.

관절 조그 ​

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

관절 조그 ​

  1. 1

    연결 상태 확인

    상단의 초록색 CONNECTED 표시는 UI가 로봇과 연결되어 있다는 뜻입니다. 연결된 상태에서만 로봇을 조작할 수 있습니다.

  2. 2

    동작 메뉴 열기

    왼쪽 메뉴에서 동작을 눌러 로봇을 움직이는 화면으로 이동합니다.

  3. 3

    현재 자세 확인

    왼쪽 위에서 로봇의 현재 위치를 볼 수 있습니다. X·Y·Z는 TCP(툴 끝점)의 위치(mm), RX·RY·RZ는 자세(°), AA는 팔꿈치 자세(arm angle)이고, J0~J6은 각 관절의 각도입니다.

  4. 4

    조그 방식 선택

    오른쪽 위 탭에서 조그 방식을 고릅니다. Global·Local·User는 좌표계를 기준으로 TCP를 직선·회전 이동시키고, Joint는 관절 하나씩 돌립니다.

  5. 5

    Joint 탭 선택

    먼저 관절을 직접 돌려 봅니다. Joint 탭을 누르세요.

  6. 6

    관절 돌려 보기

    J0~J6 각 관절의 + / − 버튼을 눌러 보세요. 누르고 있는 동안만 움직이고, 손을 떼면 멈춥니다. 누를 때마다 3D 로봇이 회전하고 관절 값이 함께 바뀌는 것을 확인하세요. 3D 모델과 숫자는 항상 같은 로봇 상태를 보여줍니다. (누른 직후 아주 짧은 지연이 있을 수 있습니다.)

직교 조그 ​

  1. 1

    동작 메뉴 열기

    왼쪽 메뉴에서 동작을 눌러 로봇을 움직이는 화면으로 이동합니다.

  2. 2

    Global 탭 선택

    TCP를 직선으로 움직여 봅니다. Global 탭을 누르세요. Global은 로봇 베이스 기준 좌표계입니다.

  3. 3

    X·Y·Z 방향으로 이동

    X, Y, Z와 RX·RY·RZ, AA의 + / − 버튼을 눌러 보세요. X·Y·Z는 누르는 방향으로 TCP가 직선 이동하고 다른 위치 값은 거의 그대로입니다. RX·RY·RZ는 베이스 좌표계의 해당 축을 중심으로 TCP를 회전시키므로, 현재 자세에 따라 누른 항목이 아닌 다른 각도 값이 함께 바뀔 수 있습니다. 팔이 닿을 수 없는 위치로는 더 나아가지 않고 멈춥니다.

속도 비율과 긴급 정지 ​

  1. 1

    동작 메뉴 열기

    왼쪽 메뉴에서 동작을 눌러 로봇을 움직이는 화면으로 이동합니다.

  2. 2

    속도 비율 조절

    화면 아래쪽 슬라이더는 로봇 이동 속도의 비율(%)이며, 조그 속도에도 이 비율이 적용됩니다. 슬라이더를 움직여 값을 바꿔 보세요. 실제 로봇을 조작할 때는 처음에 낮게 두고 시작하세요.

  3. 3

    긴급 정지 위치 기억하기

    오른쪽 위의 긴급 정지 버튼은 어떤 화면에서든 항상 보입니다. 실제 로봇을 조작할 때는 위험 상황에서 바로 누를 수 있도록 위치를 먼저 확인하세요.

다음 단계 ​

  • 조그로 맞춘 위치를 포인트로 저장하는 방법 (작성 예정)
