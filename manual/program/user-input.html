사용자 입력 ​

사용자 입력은 프로그램을 실행하는 도중 사용자에게 값을 묻고 답을 받아 이어서 실행하는 명령입니다. 작업자가 현장에서 값을 확인하거나 다음 동작을 직접 고르게 하고 싶을 때 사용합니다. 명령은 두 가지 동작 중 하나로 설정합니다.

동작하는 일
사용자 입력선언해 둔 변수의 값을 사용자가 입력하게 합니다. 실행 중 변수 이름과 현재 값이 표시된 창이 나타나고, 사용자가 값을 입력하면 이어서 진행합니다.
사용자 선택질문과 선택지를 보여 주고 사용자가 고른 선택지의 번호(0부터)를 변수에 저장합니다.

이 문서에서는 프로그램 화면에서 다음을 해 봅니다.

  • 사용자 입력 명령을 추가하고 입력받을 변수 정하기
  • 같은 명령을 사용자 선택으로 바꾸고 질문·선택지 정하기

준비

프로그램이 하나 열려 있어야 합니다(새 프로그램 만들기). 사용자 입력 동작은 변수선언으로 먼저 선언한 변수가 있어야 고를 수 있습니다.

사용자 입력 동작 ​

설정 화면의 옵션에서 사용자 입력을 고른 화면입니다. 앞에서 선언한 변수 user_name(STRING)이 있는 프로그램입니다.

번호항목설명
①옵션사용자 입력과 사용자 선택 중 동작을 고릅니다.
②변수 유형입력받을 변수의 유형입니다. STRING, NUMERIC, BOOLEAN, LIST, DICTIONARY, VARIABLE 중에서 고르며, 유형을 바꾸면 ③이 그 유형의 변수 목록으로 바뀝니다.
③변수 선택입력받을 변수입니다. 이 명령보다 앞에서 선언한 변수 중 ②에서 고른 유형의 변수만 나타납니다. 고를 수 있는 변수가 없으면 "변수를 선택해주세요."라고 표시되고 저장할 수 없습니다.
④닫기설정 화면을 닫습니다. 저장하지 않은 변경이 있으면 저장하지 않고 닫을지 묻습니다.
⑤저장설정을 적용합니다. 트리의 사용자 입력 옆에 STRING: user_name처럼 유형과 변수 이름이 표시됩니다.

프로그램을 실행해 이 명령에 이르면 프로그램이 멈추고 변수 이름과 현재 값이 표시된 창이 나타납니다. 사용자가 값을 입력해 확인하면 이어서 진행합니다.

사용자 선택 동작 ​

옵션에서 사용자 선택을 고르면 설정 화면이 팝업 설정과 선택지로 바뀝니다.

번호항목설명
①질문 메시지사용자에게 보여 줄 질문입니다. 비워 두면 저장할 수 없습니다.
②선택한 번호를 저장할 변수 이름사용자가 고른 선택지의 번호를 저장할 변수 이름입니다. 비워 두면 저장할 수 없습니다.
③선택 지연시간 (초)선택을 기다리는 시간입니다. 기본값은 60입니다.
④타임아웃이 발생했을 때 선택할 번호타임아웃이 발생했을 때 선택할 선택지 번호입니다. 기본값은 0입니다.
⑤선택지사용자에게 보여 줄 선택지 목록입니다. 기본으로 0번 No, 1번 Yes 두 개가 있으며, 문구를 바꿀 수 있습니다. 앞의 숫자가 변수에 저장되는 번호입니다.
⑥선택지 추가선택지를 한 줄 더합니다. 최대 20개까지 추가할 수 있습니다. 목록 아래의 선택지 추가 버튼도 같은 동작입니다.
⑦닫기설정 화면을 닫습니다.
⑧저장설정을 적용합니다. 트리의 명령 이름이 사용자 선택으로 바뀌고 질문 메시지가 옆에 표시됩니다.

선택지는 0번과 1번을 지울 수 없고, 2번부터는 줄 오른쪽의 삭제 버튼으로 지울 수 있습니다. 입력칸을 누르면 화면 키보드가 나타나며, 키보드의 Close로 닫습니다.

프로그램을 실행하면 ​

프로그램이 사용자 입력·사용자 선택에 이르면 프로그램이 멈추고 창이 나타납니다. 사용자가 응답하면 이어서 실행합니다.

사용자 입력 창 ​

사용자 변수 값 변경 창이 나타나며 변수 유형과 변수(변수 이름과 현재 값), 새 값을 적는 적용할 값, 유형별 입력 예시가 표시됩니다.

버튼하는 일
반영 후 계속입력한 값을 변수에 적용하고 이어서 실행합니다.
스킵값을 바꾸지 않고 이어서 실행합니다.
프로그램 정지프로그램을 멈춥니다.

적용할 값은 변수 유형에 맞게 적어야 합니다. 맞지 않으면 반영되지 않습니다.

변수 유형적는 방법
STRING큰따옴표로 감쌉니다. 예: "Robot_Mode_1"
NUMERIC정수나 실수입니다. 예: 100, 3.14, -45.5
BOOLEANTrue 또는 False
LIST대괄호로 감쌉니다. 예: [0, -90, 90, -90, -90, 0, 0]
DICTIONARY중괄호로 감쌉니다. 예: {"tool_name": "Gripper_A"}

사용자 선택 창 ​

질문 메시지가 창 제목이 되고, 선택지가 0: No, 1: Yes처럼 번호와 함께 버튼으로 나타납니다. 선택지를 누르면 그 번호가 지정한 변수에 저장되고 프로그램이 이어서 실행됩니다.

버튼하는 일
선택지 버튼그 번호를 변수에 저장하고 이어서 실행합니다.
스킵고르지 않고 이어서 실행합니다. 변수 값은 바뀌지 않습니다.
프로그램 정지프로그램을 멈춥니다.

선택 지연시간(초) 안에 고르지 않으면 타임아웃이 발생했을 때 선택할 번호의 선택지가 골라진 것으로 처리됩니다.

직접 해 보기 ​

예제 프로그램은 문자열 변수 user_name과 숫자 변수 answer를 선언하고, 끝의 디버그가 두 값을 보여 줍니다. 실습은 두 가지이며 어느 쪽부터 해도 되고, 앞의 실습을 하지 않아도 시작할 수 있습니다. 실습을 다시 시작하면 바꾼 값은 처음 상태로 돌아갑니다.

사용자 입력 만들기 ​

가운데 빈 영역에 사용자 입력을 넣고 실행해 입력한 값이 변수에 적용되는 것을 확인하는 과정입니다.

  1. 빈 영역에 사용자 입력을 추가하고 설정 화면에서 변수 유형(STRING)과 변수(user_name)를 확인한 뒤 저장합니다.
  2. 재생(▶)을 누르고 프로그램 변경 확인 창에서 저장을 누르면 사용자 변수 값 변경 창이 나타납니다. 적용할 값에 정해진 값 "Robot_A"를 큰따옴표까지 포함해 입력합니다. 입력한 값이 정해진 값과 같아야 다음으로 넘어갈 수 있으며, 공백은 다르게 입력해도 같은 값으로 봅니다. 건너뛰면 자동으로 입력됩니다.
  3. 반영 후 계속을 누르면 디버그 창에 user_name: "Robot_A"가 표시됩니다. 문자열은 디버그 창에서 큰따옴표로 감싸 표시되고, 아직 바꾸지 않은 answer는 0.0입니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    예제 프로그램은 문자열 변수 `user_name`과 숫자 변수 `answer`를 선언하고, 끝의 디버그가 두 값을 보여 줍니다. 가운데 빈 영역에 사용자 입력 명령을 넣습니다.

  2. 2

    넣을 위치 고르기

    프로그램 트리에서 명령을 넣을 위치의 빈 영역을 누릅니다.

  3. 3

    명령어 목록 열기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 명령어 목록이 열립니다.

  4. 4

    사용자 입력 고르기

    공통 명령어에서 사용자 입력을 누릅니다. 선택한 자리에 사용자 입력 명령이 추가됩니다.

  5. 5

    사용자 입력 열기

    트리에 추가된 사용자 입력을 누르면 오른쪽에 설정 화면이 열립니다.

  6. 6

    사용자 입력 설정 화면

    설정 화면의 옵션에서 사용자 입력과 사용자 선택 중 하나를 고릅니다. 사용자 입력은 변수 설정에서 입력받은 값을 저장할 변수의 유형과 이름을 정합니다. 변수 선택에는 앞에서 선언한 변수 중 고른 유형의 변수가 나타납니다.

  7. 7

    저장

    저장을 누르면 트리의 사용자 입력 옆에 `STRING: user_name`처럼 유형과 변수 이름이 표시됩니다.

  8. 8

    프로그램 실행

    재생(▶) 버튼을 눌러 프로그램을 실행합니다. 프로그램을 바꾼 뒤이므로 저장 확인 창이 나타납니다.

  9. 9

    저장 후 실행

    프로그램을 바꾼 뒤 실행하면 **프로그램 변경 확인** 창이 나타나 저장 후 실행할지 묻습니다. **저장**을 누르면 저장하고 실행합니다.

  10. 10

    사용자 변수 값 변경 창

    사용자 입력 명령에 이르면 프로그램이 멈추고 **사용자 변수 값 변경** 창이 나타납니다. **변수 유형**(STRING)과 **변수**(변수 이름과 현재 값)가 표시되고, **적용할 값**에 새 값을 입력합니다. 문자열은 큰따옴표로 감싸서 입력하며(예: `"Robot_A"`), 창 아래에 유형별 입력 예시가 있습니다.

  11. 11

    반영 후 계속

    **반영 후 계속**을 누르면 입력한 값이 변수에 적용되고 프로그램이 이어서 실행됩니다. **스킵**은 값을 바꾸지 않고 이어서 실행하고, **프로그램 정지**는 프로그램을 멈춥니다.

  12. 12

    바뀐 값 확인

    입력한 값이 변수에 적용되어, 이어지는 디버그 창에 `user_name: "Robot_A"`가 표시됩니다. 문자열은 큰따옴표로 감싸 표시되고, 아직 바꾸지 않은 `answer`는 `0.0`입니다. 트리에는 지금 실행 중인 명령이 노란색으로 표시됩니다.

사용자 선택으로 바꾸기 ​

사용자 입력이 들어 있는 프로그램에서 그 명령을 사용자 선택으로 바꿔 실행하는 과정입니다.

  1. 트리의 사용자 입력 설정 화면을 열어 사용자 선택으로 바꿉니다. 질문 메시지에 Continue?, 선택한 번호를 저장할 변수 이름에 answer를 입력하고 저장합니다.
  2. 재생(▶)을 누르고 프로그램 변경 확인 창에서 저장을 누르면 질문과 선택지가 있는 창이 나타납니다. 1: Yes를 누르면 디버그 창에 answer: 1.0이 표시됩니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    예제 프로그램에는 문자열 변수 `user_name`을 위한 사용자 입력 명령이 들어 있습니다. 이 명령을 사용자 선택으로 바꿉니다.

  2. 2

    편집 아이콘 누르기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 편집 화면이 열립니다.

  3. 3

    사용자 입력 선택

    트리에서 사용자 입력을 누르면 선택됩니다.

  4. 4

    사용자 입력 설정 화면 열기

    선택된 사용자 입력을 한 번 더 누르면 설정 화면이 열립니다.

  5. 5

    옵션 목록 열기

    옵션 선택 상자를 누르면 사용자 입력과 사용자 선택 목록이 열립니다.

  6. 6

    사용자 선택 고르기

    목록에서 사용자 선택을 누르면 설정 화면이 팝업 설정과 선택지로 바뀝니다.

  7. 7

    사용자 선택 설정 화면

    사용자 선택은 팝업 설정에서 질문 메시지, 선택한 번호를 저장할 변수 이름, 선택 지연시간(초), 타임아웃이 발생했을 때 선택할 번호를 정하고, 선택지에서 보여줄 문구를 적습니다. 선택지는 기본으로 두 개(No, Yes)이며 최대 20개까지 추가할 수 있습니다.

  8. 8

    질문 메시지 입력

    질문 메시지에 사용자에게 보여줄 문구를 입력합니다. 예에서는 `Continue?`를 입력합니다.

  9. 9

    저장할 변수 이름 입력

    선택한 번호를 저장할 변수 이름을 입력합니다. 예에서는 `answer`를 입력합니다.

  10. 10

    저장

    저장을 누르면 트리의 명령 이름이 사용자 선택으로 바뀌고 질문 메시지가 옆에 표시됩니다.

  11. 11

    프로그램 실행

    재생(▶) 버튼을 눌러 프로그램을 실행합니다. 프로그램을 바꾼 뒤이므로 저장 확인 창이 나타납니다.

  12. 12

    저장 후 실행

    프로그램을 바꾼 뒤 실행하면 **프로그램 변경 확인** 창이 나타나 저장 후 실행할지 묻습니다. **저장**을 누르면 저장하고 실행합니다.

  13. 13

    사용자 선택 창

    사용자 선택 명령에 이르면 프로그램이 멈추고 창이 나타납니다. 창 제목은 **질문 메시지**이고, 선택지가 `0: No`, `1: Yes`처럼 **번호와 함께 버튼**으로 표시됩니다. 아래에는 **스킵**(고르지 않고 이어서 실행)과 **프로그램 정지** 버튼이 있습니다. 선택지를 누르면 그 번호가 `answer` 변수에 저장되고 프로그램이 이어서 실행됩니다. 트리에는 지금 실행 중인 명령이 노란색으로 표시됩니다.

  14. 14

    선택 결과 확인

    1번(Yes)을 고르면 디버그 창에 `answer: 1.0`이 표시됩니다. 이제 이 명령은 사용자 선택이므로 `user_name`은 바뀌지 않고 처음 값(빈 문자열)입니다.
