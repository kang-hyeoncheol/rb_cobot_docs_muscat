설정 ​

설정은 프로그램 실행 도중 로봇의 동작 설정을 바꾸는 명령입니다. 충돌 감지, 속도, 좌표계, 직접 교시, 입출력 마스크 등 여러 종류의 설정을 하나의 명령으로 바꿀 수 있습니다. 설정 명령 하나는 한 종류의 설정만 담으므로, 여러 설정을 바꾸려면 설정 명령을 여러 개 넣습니다.

이 문서에서는 프로그램 화면에서 다음을 해 봅니다.

  • 설정 명령을 추가하고 외부 충돌 감지를 켜는 설정 만들기
  • 같은 명령의 종류를 속도 조절 바로 바꾸기
  • 고를 수 있는 설정 종류 확인하기

안전

설정은 프로그램을 실행하면 로봇의 동작 설정이 실제로 바뀌는 명령입니다. 충돌 감지를 끄거나 속도를 높이면 안전에 영향을 줄 수 있으니 값을 확인하고 사용합니다.

설정 화면 ​

트리의 설정을 누르면 열리는 화면입니다. 설정 명령을 처음 추가하면 외부 충돌 감지가 골라져 있고 상태는 끄기입니다.

번호항목설명
①옵션바꾸려는 설정의 종류입니다. 아래 영역이 고른 종류의 설정 항목으로 바뀝니다. 종류는 아래 표에서 모두 설명합니다.
②상태외부 충돌 감지를 끄기·켜기 중에서 고릅니다.
③정지 모드동작 일시 정지·회피 정지 중에서 고릅니다.
④둔감도0~100% 슬라이더입니다. 값이 클수록 더 큰 힘이 가해져야 충돌로 판단합니다.
⑤닫기설정 화면을 닫습니다. 저장하지 않은 변경이 있으면 저장하지 않고 닫을지 묻습니다.
⑥저장설정을 적용하고 설정 화면을 닫습니다. 트리의 설정 옆에 설정 내용이 표시됩니다.

②~④는 외부 충돌 감지를 골랐을 때의 항목이며, 설정 > 일반 > 충돌 감지의 외부 충돌 설정과 같은 항목입니다. 다른 종류를 고르면 ②~④ 자리에 그 종류의 항목이 나타납니다. 트리에는 Out Collision - On, Evasion Stop, Threshold: 50%처럼 고른 값이 요약되어 표시됩니다.

종류를 바꾸면

옵션에서 다른 종류를 고르면 아래 영역이 그 종류의 항목으로 바뀝니다. 저장하면 마지막으로 고른 종류의 설정만 이 명령에 남습니다.

직접 해 보기 ​

설정 명령을 추가해 외부 충돌 감지를 켜고 회피 정지로 정한 뒤, 같은 명령을 속도 조절 바 설정으로 바꿔 봅니다. 실습의 로봇은 실제로 움직이지 않으며 프로그램을 실행하지 않습니다. 다음 순서로 진행합니다.

  1. 트리의 빈 영역을 눌러 위치를 정하고 편집 아이콘으로 명령어 목록을 연 뒤 설정을 추가합니다. 처음에는 외부 충돌 감지가 골라져 있고 상태는 끄기입니다.
  2. 트리에서 설정을 눌러 설정 화면을 엽니다.
  3. 상태를 켜기, 정지 모드를 회피 정지로 고르고 둔감도 슬라이더를 움직여 봅니다.
  4. 저장을 누르면 트리의 설정 옆에 Out Collision - On과 정지 모드, 둔감도가 표시됩니다.
  5. 설정을 다시 열어 옵션을 속도 조절 바로 바꾸고 슬라이더로 값을 정합니다.
  6. 저장을 누르면 트리의 설정 옆 내용이 속도 조절 바 설정으로 바뀝니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    넣을 위치 고르기

    프로그램 트리에서 명령을 넣을 위치의 빈 영역을 누릅니다.

  2. 2

    명령어 목록 열기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 명령어 목록이 열립니다.

  3. 3

    설정 고르기

    매니퓰레이트 명령어에서 설정을 누릅니다. 트리에 설정이 추가됩니다.

  4. 4

    트리에 추가된 설정

    트리에 설정이 추가되고 옆에 설정 내용이 표시됩니다. 처음에는 외부 충돌 감지를 끄는 설정(Out Collision - Off)입니다.

  5. 5

    설정 열기

    트리에서 설정을 누르면 오른쪽에 설정 화면이 열립니다.

  6. 6

    설정 화면

    설정 화면의 맨 위 옵션에서 바꾸려는 설정 종류를 고르면, 아래 영역이 그 종류의 설정 항목으로 바뀝니다. 처음에는 외부 충돌 감지가 골라져 있습니다.

  7. 7

    상태 목록 열기

    외부 충돌 감지의 상태 선택 상자를 누르면 끄기와 켜기 목록이 열립니다.

  8. 8

    켜기 고르기

    목록에서 켜기를 누릅니다.

  9. 9

    정지 모드 목록 열기

    정지 모드 선택 상자를 누르면 동작 일시 정지와 회피 정지 목록이 열립니다.

  10. 10

    회피 정지 고르기

    목록에서 회피 정지를 누릅니다.

  11. 11

    정한 값 확인

    상태를 켜기, 정지 모드를 회피 정지로 정하면 저장한 뒤 트리에 Out Collision - On, Evasion Stop과 둔감도(Threshold)가 표시됩니다. 저장하기 전에는 적용되지 않습니다.

  12. 12

    둔감도 조절

    둔감도 슬라이더를 눌러 0~100% 사이로 조절합니다. 오른쪽에 현재 값이 퍼센트로 표시됩니다.

  13. 13

    설정 저장

    저장을 누르면 설정이 적용되고 설정 화면이 닫힙니다. 트리의 설정 옆에 설정 내용이 표시됩니다.

  14. 14

    저장된 설정 확인

    트리의 설정 옆에 Out Collision - On과 정지 모드, 둔감도(Threshold)가 표시됩니다. 프로그램을 실행하면 이 지점에서 외부 충돌 감지 설정이 바뀝니다.

  15. 15

    다시 열기

    설정 명령의 종류는 언제든 바꿀 수 있습니다. 트리에서 설정을 눌러 설정 화면을 엽니다.

  16. 16

    옵션 목록 열기

    맨 위 옵션 선택 상자를 누르면 설정 종류 목록이 열립니다. 목록은 스크롤해서 볼 수 있습니다.

  17. 17

    속도 조절 바 고르기

    목록에서 속도 조절 바를 누르면 아래 영역이 속도 조절 바 설정으로 바뀝니다.

  18. 18

    속도 조절 바 값 정하기

    속도 조절 바(%) 슬라이더를 눌러 0~100% 사이의 값을 정합니다. 오른쪽에 현재 값이 표시됩니다.

  19. 19

    설정 저장

    저장을 누르면 설정이 적용됩니다. 트리의 설정 옆에 Speed와 정한 값이 표시됩니다.

  20. 20

    바뀐 설정 확인

    트리의 설정 옆 내용이 속도 조절 바 설정(Speed - 값)으로 바뀝니다. 설정 명령 하나는 한 종류의 설정만 가지므로, 여러 설정을 바꾸려면 설정 명령을 여러 개 넣습니다.
