워크스페이스 편집 화면 ​

워크스페이스를 만들거나 불러오면 이름·저장 버튼, 오브젝트 목록, 속성 입력 영역이 나타납니다. 이 페이지에서는 워크스페이스 전체 관리, 오브젝트 선택·관리, 선택한 오브젝트 편집을 구분해 설명합니다.

새로 만들기와 불러오기, 작업대 배치 예제는 워크스페이스 사용 방법을 참고하세요.

열린 화면의 구성 ​

다음은 베이스 탭에서 demo_cell을 만들고 직육면체와 원기둥을 추가한 뒤, 직육면체 하나를 선택한 상태입니다. 새 워크스페이스를 만들기만 했다면 목록은 비어 있으며, 오브젝트를 선택하기 전에는 속성 대신 선택 안내가 표시됩니다.

번호영역역할
①워크스페이스 관리이름·저장 상태 확인, 되돌리기·다시 실행, 전체 관리 메뉴, 닫기·저장
②오브젝트 리스트도형·파일 추가, 편집할 항목 선택, 이름 변경·숨기기·삭제
③오브젝트 속성선택한 항목의 위치·회전·크기를 수치로 편집
④3D 편집 도구위치·회전·크기 중 3D 화면에서 조작할 도구 선택

베이스는 로봇 주변 물체를, 툴은 툴에 부착할 물체를 구성합니다. 툴이 여러 개인 로봇에서는 툴별 탭이 나뉩니다. 편집할 대상에 맞는 탭을 먼저 선택합니다.

상단 관리 영역과 목록(①·②) ​

아래 이미지는 오브젝트 추가(⑪)를 펼친 상태입니다. ×는 추가 항목을 접는 버튼이며, 워크스페이스를 닫는 닫기(⑧)와 다릅니다.

번호항목설명
⑤이름·저장 상태현재 워크스페이스 이름을 표시합니다. 이름을 더블클릭하거나 ⑦의 이름 변경을 선택해 수정합니다. Enter로 확정하고 Esc로 취소합니다.
⑥되돌리기·다시 실행왼쪽 화살표는 직전 편집을 되돌리고, 오른쪽 화살표는 되돌린 편집을 다시 적용합니다. 해당 이력이 없으면 비활성화됩니다.
⑦워크스페이스 메뉴현재 워크스페이스 전체를 관리하는 메뉴를 엽니다. 개별 항목의 메뉴(⑫)와 구분합니다.
⑧닫기편집 중인 워크스페이스를 닫습니다. 저장되지 않은 변경이 있으면 확인 창이 표시됩니다.
⑨저장현재 변경 내용을 즉시 저장합니다. 저장 중이거나 저장할 변경이 없으면 비활성화됩니다.
⑩선택여러 항목을 체크하는 모드로 전환합니다. 모드가 켜지면 선택 취소로 표시됩니다.
⑪오브젝트 추가+를 눌러 도형·파일 추가 항목을 펼치고, ×를 눌러 접습니다.
⑫오브젝트 메뉴해당 항목의 이름 변경, 씬에서 숨기기·다시 표시, 오브젝트 삭제를 선택합니다.

이름 옆의 저장 표시(⑤) ​

편집 내용은 자동저장됩니다. 저장 안 됨은 아직 저장되지 않은 변경이 있다는 뜻입니다. 저장이 끝나면 저장됨이 잠시 표시된 뒤 사라집니다. 저장됨 표시가 사라졌다는 이유만으로 미저장 상태인 것은 아닙니다. 되돌리기·다시 실행으로 정한 최종 상태는 저장 버튼으로 저장할 수 있습니다.

워크스페이스 메뉴(⑦) ​

메뉴동작·사용 조건
새로 만들기새 이름으로 빈 워크스페이스를 만듭니다.
불러오기저장된 워크스페이스를 선택해 엽니다. 미저장 변경이 있으면 다른 구성을 열기 전에 확인합니다.
이름 변경현재 워크스페이스의 이름을 수정합니다.
사본 만들기현재 구성을 다른 이름으로 복사합니다. 항목이 없거나 저장 중이면 비활성화됩니다.
삭제확인 후 현재 워크스페이스의 저장된 오브젝트를 삭제합니다. 개별 도형 삭제와 구분합니다.
오브젝트 전체 삭제현재 편집 목록의 모든 항목을 비웁니다. 항목이 없으면 비활성화됩니다.
마지막 저장 상태로 되돌리기미저장 변경을 버리고 마지막 저장 상태를 불러옵니다. 미저장 변경이 없으면 비활성화됩니다. 자동저장 후에는 그 저장 상태가 기준입니다.

추가 항목과 개별 선택(⑪·⑫) ​

직육면체·원기둥·구는 도형을 추가하고, 불러온 파일은 3D 파일을 선택하는 창을 엽니다. 도형은 최대 5개, 파일은 한 워크스페이스에 1개를 둘 수 있습니다. 기존 파일이 있으면 교체 여부를 확인합니다. 이 페이지의 실습에서는 파일 업로드를 지원하지 않습니다.

일반 모드에서 목록의 항목을 누르면 해당 오브젝트가 선택되고 ③에 속성이 표시됩니다. 이미 선택한 항목을 다시 누르면 선택이 해제됩니다. 항목을 더블클릭하거나 ⑫의 이름 변경을 선택하면 개별 오브젝트 이름을 수정할 수 있습니다.

⑫의 씬에서 숨기기는 목록에 항목을 남겨 둔 채 3D 화면에서만 가립니다. 숨긴 항목은 목록에서 흐리게 표시되고 숨김 아이콘이 붙습니다. 같은 메뉴의 씬에 다시 표시로 복원합니다. 오브젝트 삭제는 목록과 3D 화면에서 항목을 제거합니다.

목록의 로딩 아이콘은 불러오는 중임을, 경고 아이콘은 저장 실패 또는 파일을 불러오지 못한 상태를 나타냅니다.

속성 입력 영역(③) ​

다음은 도형 하나를 선택한 상태입니다. 위치·회전·크기는 함께 표시되며, 3D 편집 도구(④)의 선택과 관계없이 수치로 입력할 수 있습니다.

번호항목설명
⑬위치 X·Y·Z각 축 방향의 위치를 mm로 입력합니다.
⑭회전 RX·RY·RZ각 축의 회전 값을 ° 단위로 입력합니다.
⑮크기 SX·SY·SZ도형의 각 방향 치수를 mm로 입력합니다. 배율을 입력하는 칸이 아닙니다. 불러온 파일에는 크기 입력이 표시되지 않습니다.
⑯초기화선택한 항목의 위치·회전을 0으로 되돌립니다. 도형 크기는 기본 치수로 되돌립니다. 이름이나 다른 항목은 초기화하지 않습니다.

입력칸을 누르면 숫자 키패드가 열립니다. 키패드에서는 Set, 키보드에서는 Enter로 값을 적용합니다. 입력칸 양옆의 −·+ 버튼으로 위치·크기를 1mm, 회전을 0.1°씩 조정합니다. 입력 중 키보드의 ↑·↓ 키로도 같은 단위로 조정할 수 있습니다.

3D 편집 도구(④) ​

오브젝트를 하나 선택하면 3D 화면 왼쪽에 도구가 나타납니다. 여기서 고른 모드는 3D 화면의 조작 핸들(기즈모)에 적용됩니다.

도구3D 화면에서 하는 작업
위치이동 핸들을 끌어 선택한 오브젝트의 위치를 바꿉니다.
회전회전 핸들을 끌어 오브젝트의 방향을 바꿉니다.
크기크기 핸들을 끌어 도형의 치수를 바꿉니다. 불러온 파일에는 이 도구가 표시되지 않습니다.

여러 항목을 체크하는 선택 모드에서는 이 도구가 표시되지 않습니다. 위치·방향·크기를 정확한 값으로 맞추려면 ③의 수치 입력을 사용합니다.

여러 항목을 관리하는 선택 모드(⑩) ​

선택을 누르면 각 항목에 체크박스가 나타납니다. 아래는 두 항목 중 하나를 체크한 상태입니다.

번호항목설명
⑰체크 목록항목을 눌러 체크하거나 해제합니다. 일반 모드의 단일 편집 대상 선택과 구분합니다.
⑱선택 수·일괄 작업체크한 수와 숨기기 N, 삭제 N 버튼을 표시합니다. 아무것도 체크하지 않으면 버튼이 비활성화됩니다.

숨기기 N은 체크한 항목을 씬에서 숨기고, 삭제 N은 체크한 항목을 삭제합니다. 작업을 적용하면 선택 모드가 종료됩니다. 작업 없이 나가려면 선택 취소를 누릅니다.

직접 해 보기 ​

편집 기능은 워크스페이스의 실습에서 하나씩 연습합니다. 아래 자유 실습은 Welding cell이 열려 있는 상태로 시작하며, 이 페이지의 메뉴와 선택 모드를 사용해 볼 수 있습니다.

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

간단한 사용 예시 ​

  1. 일반 모드에서 편집할 도형 하나를 선택합니다. ③에 속성이 나타나고 ④에 3D 편집 도구가 보입니다.
  2. 위치 X(⑬)에 500을 입력하고 Set을 누릅니다. 3D 화면에서 도형의 위치가 바뀌는지 확인합니다.
  3. 다른 도형도 함께 숨기려면 선택(⑩)을 누르고 원하는 항목을 체크한 뒤 숨기기 N(⑱)을 누릅니다.
  4. 다시 표시할 때는 일반 모드에서 각 항목의 ⋮(⑫) → 씬에 다시 표시를 사용합니다.

여러 도형의 위치·크기를 입력하고 저장 후 다시 여는 전체 예제는 작업대와 원기둥 만들기로 이어집니다.
