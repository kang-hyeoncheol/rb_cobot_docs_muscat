교정 ​

TCP와 사용자 좌표계, 부가 축을 교정하는 메뉴입니다. 맨 위 목록에서 교정 종류를 고르면 아래 화면이 바뀝니다.

화면에서 파란 테두리로 표시한 곳입니다. 오른쪽 메뉴의 항목을 누르면 옆에 이 패널이 열립니다.

직접 해 보기 ​

TCP 위치 교정을 두 가지 실습으로 해 볼 수 있습니다. 앞의 실습을 하지 않아도 시작할 수 있습니다. 목록은 이 화면 안에서만 유지되므로 실습을 시작할 때마다 비어 있는 상태에서 시작합니다.

포인트가 부족할 때 경고 확인하기 ​

포인트를 하나만 추가하고 적용을 눌러 경고를 확인합니다.

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

포인트를 쌓아 계산 결과 확인하기 ​

자세를 바꿔 가며 포인트를 4개 이상 쌓고 적용해 계산 결과를 확인합니다.

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

패널 화면 ​

위 화면은 가상 로봇(데모)에서 캡처한 것이라 값은 실제 로봇과 다를 수 있습니다.

모든 교정 버튼은 로봇이 움직이는 중이거나 연결되지 않은 상태(DISCONNECT)에서는 비활성화됩니다.

교정 종류 ​

TCP 위치 교정 ​

  • 추가: 현재 관절 각도(J0~J6, 단위 °)를 포인트(P1, P2, …)로 목록에 더합니다. TCP 좌표가 아니라 관절 값이 저장되며, 목록에도 각도로 표시됩니다. 누를 때마다 그 순간 로봇의 자세가 한 줄씩 쌓이므로, 로봇을 움직여 자세를 바꾼 뒤 다시 누르세요.
  • 초기화: 목록을 비웁니다. 목록 한 줄의 X를 누르면 그 포인트만 지웁니다.
  • 적용: 목록의 관절 값을 모두 컨트롤러에 보내 TCP 위치를 계산하게 합니다. 목록이 비어 있으면 비활성화됩니다.
  • 포인트가 없을 때는 "포인트를 추가하세요."라고 표시됩니다.

포인트를 쌓는 방법 ​

  • 다른 메뉴로 이동하면 목록이 사라집니다. 포인트 목록은 이 화면 안에서만 유지되어, 조그 같은 다른 메뉴를 눌렀다 돌아오면 비어 있습니다(가상 로봇에서 확인).
  • 그래서 이 화면을 벗어나지 않고 로봇을 움직여야 합니다. 3D 화면 오른쪽의 손 모양 버튼(고스트 로봇)을 눌러 스위치를 켜면 3D 화면에 Control Panel 버튼이 나타나고, 이를 누르면 조그 패널이 이 화면 위에 열립니다. 가상 로봇에서는 이 패널의 + / − 버튼으로 자세를 바꾼 뒤 추가를 눌러 포인트를 쌓을 수 있었습니다.
  • 실제 로봇에서 어떤 방식으로 자세를 바꾸는 것이 권장되는지(예: 직접 교시)는 확인하지 못했습니다.

적용을 누르면 ​

컨트롤러 코드(rb_service/calibration/calibration.cpp의 Auto_TCP_Position)에서 확인한 동작입니다.

  • 포인트는 4개 이상 필요합니다. 그보다 적으면 경고만 나오고 계산하지 않습니다.
  • 계산은 각 포인트의 플랜지 위치와 자세에서, 포인트마다 계산한 TCP 끝점이 서로 같은 곳에 모이는 TCP 오프셋(X·Y·Z) 을 구합니다. 그래서 TCP 끝을 같은 한 점에 둔 채 자세(회전)를 서로 다르게 바꿔 가며 포인트를 쌓아야 합니다. 자세가 거의 같은 포인트들만 있으면 계산에 쓸 수 있는 조합이 부족해 경고가 나옵니다.
  • 오차가 큰 포인트 조합은 걸러 내며 다섯 번까지 반복해 값을 다듬습니다.
  • 결과는 "Auto TCP Result"라는 메시지로 X, Y, Z와 오차(RMSE)가 나옵니다. 이 함수는 계산 결과를 알려 줄 뿐, TCP 툴 목록의 값을 바꾸는 코드는 들어 있지 않습니다. 계산 결과를 툴에 자동으로 넣어 주는지는 이 함수만으로는 알 수 없고, 다른 곳에서 반영하는 코드는 찾지 못했습니다. 결과를 툴에 쓰려면 결과 값을 확인한 뒤 툴 설정에서 입력하는 것으로 보이지만 확인하지는 못했습니다.
  • 이 화면의 적용 버튼은 요청만 보내고 응답을 따로 처리하지 않습니다. 결과 메시지가 앱의 어느 곳에 어떻게 표시되는지는 확인하지 못했습니다.

데모에서는

가상 로봇에서도 적용을 누르면 위 컨트롤러 코드를 같은 순서로 옮겨 계산하고, 결과(또는 경고) 메시지를 띄웁니다. 플랜지 좌표를 URDF 기준으로 가정하고 단위를 mm로 본 계산이라 실제 컨트롤러의 값과 같다고 보장할 수는 없습니다. 계산 결과는 메시지로만 나오며 TCP 툴 값은 바뀌지 않습니다.

TCP 회전 교정 ​

옵션 목록에서 전역 좌표계, 로컬 좌표계, 사용자 좌표계 중 하나를 고르고 적용을 누릅니다. 컨트롤러(Auto_TCP_Orientation)는 현재 관절 각도로 플랜지 자세를 구한 뒤, 고른 좌표계의 축에 TCP가 맞춰지도록 하는 RX·RY·RZ를 계산해 "Auto TCP Orientation Result" 메시지로 알려 줍니다. 위치 교정과 마찬가지로 이 함수에는 툴 값을 저장하는 코드가 없습니다.

유저 좌표계: 3개 지점을 이용한 교정 ​

  1. 사용자 좌표계에서 교정할 User 0~7 중 하나를 고릅니다.
  2. 포인트 순서를 고릅니다. 선택지는 원점 → X축 → XY 평면, 원점 → Y축 → YZ 평면, 원점 → Z축 → ZX 평면이며, 고른 순서에 맞는 그림이 아래에 표시됩니다.
  3. 포인트 1~3의 X·Y·Z(mm)를 직접 입력하거나, 각 포인트의 가져오기를 눌러 현재 TCP 위치 값을 채웁니다.
  4. 저장을 누르면 입력값으로 교정을 요청합니다. 숫자가 아닌 값이 있으면 경고가 표시되고 요청하지 않습니다.

유저 좌표계: TCP 좌표계를 이용한 교정 ​

사용자 좌표계에서 User 0~7 중 하나를 고르고 저장을 누릅니다.
