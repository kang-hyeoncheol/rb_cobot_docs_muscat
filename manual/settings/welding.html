용접 장치 ​

용접 장치 설정은 로봇이 용접기와 신호를 주고받는 방법을 정합니다. 용접기와 연결하는 방식, 용접기로 보내는 신호와 용접기에서 읽는 신호를 연결할 입출력 포트, 사용하는 용접기의 하드웨어 종류, 전류·전압과 아날로그 출력값의 대응을 한 화면에서 설정합니다.

이 문서에서는 설정 > 디바이스 > 용접 화면에서 다음을 해 봅니다.

  • 용접 장치 ID를 고르고 출력 포트를 연결하기
  • 하드웨어(프로세스 타입 등)를 고르기
  • 변환 맵을 추가하고 저장하기

화면 구성 ​

왼쪽 설정 메뉴의 디바이스 > 용접을 누르면 나타나는 화면입니다. 아직 아무것도 바꾸지 않은 상태입니다.

번호영역역할
①용접 장치 옵션 설정용접기와 연결하는 방식(장치 ID)과 통신 장치의 IP·포트를 정합니다.
②용접 출력 옵션 설정로봇이 용접기로 보내는 신호를 연결할 출력 포트를 정합니다.
③용접 입력 옵션 설정용접기가 로봇으로 보내는 신호를 읽을 입력 포트를 정합니다.
④용접 하드웨어 옵션 설정사용하는 용접기의 프로세스 타입, 와이어 타입·크기, 가스 타입을 고릅니다.
⑤용접 변환 맵 설정용접 전류·전압 값과 아날로그 출력값(V)의 대응을 표로 정합니다.
⑥초기화 · 저장다섯 카드의 값을 한꺼번에 저장하거나, 저장하지 않은 값을 저장된 값으로 되돌립니다.

화면 위쪽의 저장을 눌러야 ①~⑤에서 고른 값이 적용됩니다. 초기화는 저장하지 않은 값을 저장된 값으로 되돌리며, 화면의 값이 저장된 값과 같으면 눌리지 않습니다.

용접 장치 (①) ​

번호항목설명
⑦장치 ID용접기와 연결하는 방식을 고릅니다. 아래에서 자세히 설명합니다.
⑧장치 IP통신으로 연결하는 용접기의 IP 주소입니다. 네 칸에 각각 0~255를 입력합니다.
⑨장치 포트통신으로 연결하는 용접기의 포트 번호입니다. 0~65535 범위의 숫자를 입력합니다.

장치 ID ​

선택동작
None용접기와 통신하지 않습니다. 처음 상태의 기본값입니다.
I/O Signal컨트롤 박스의 디지털·아날로그 입출력 신호로 용접기와 연결합니다. 출력(②)·입력(③) 카드에서 정한 포트를 사용합니다.
Miller M.BusModbus 통신으로 연결합니다. 장치 IP·포트로 접속하며, 연결될 때 하드웨어(④)에서 고른 프로세스·와이어·가스 종류를 용접기로 보냅니다.
Aotai M.BusModbus 통신으로 연결합니다. 장치 IP·포트로 접속하고 용접기의 상태와 전류·전압·송급 속도를 읽어 옵니다.

M.Bus의 포트

Miller M.Bus나 Aotai M.Bus를 고르고 저장하면 장치 포트는 502로 저장됩니다. 입력한 포트 값은 쓰이지 않습니다.

용접 출력 (②) ​

로봇이 용접기로 보내는 신호를 컨트롤 박스의 어느 출력 포트에 연결할지 고릅니다. 장치 ID가 I/O Signal일 때 사용합니다. 아래는 아직 아무것도 고르지 않은 상태입니다.

번호항목설명선택지
⑩아크 발생 신호아크 용접을 하는 동안 켜집니다.None, Digital Output 0~15
⑪접촉 신호접촉(터치) 동작을 하는 동안 켜집니다.None, Digital Output 0~15
⑫가스 발생 신호가스를 내보내는 동안 켜집니다.None, Digital Output 0~15
⑬와이어 인칭 신호와이어 인칭 동작 중 켜집니다.None, Digital Output 0~15
⑭와이어 재인칭 신호와이어 재인칭(반대 방향) 동작 중 켜집니다.None, Digital Output 0~15
⑮전류 설정 포트용접 전류 설정값을 변환 맵(⑤)으로 바꾼 전압을 내보냅니다.None, Analog Output 0~3
⑯전압 설정 포트용접 전압 설정값을 변환 맵(⑤)으로 바꾼 전압을 내보냅니다.None, Analog Output 0~3

None을 고른 신호는 내보내지 않습니다.

용접 입력 (③) ​

용접기가 로봇으로 보내는 신호를 컨트롤 박스의 어느 입력 포트로 읽을지 고릅니다. 장치 ID가 I/O Signal일 때 사용합니다.

번호항목설명선택지
⑰용접기 준비 신호용접기가 준비되었는지 읽습니다. None이면 항상 준비된 것으로 봅니다.None, Digital Input 0~15
⑱아크 발생 피드백아크가 발생했는지 읽습니다.None, Digital Input 0~15
⑲접촉 신호 피드백접촉 상태를 읽습니다.None, Digital Input 0~15
⑳가스 신호 피드백가스 상태를 읽습니다.None, Digital Input 0~15
㉑송급기 신호 피드백와이어 송급기 상태를 읽습니다.None, Digital Input 0~15
㉒용접기 에러 신호용접기의 에러 신호를 읽습니다.None, Digital Input 0~15
㉓전류 피드백실제 용접 전류에 해당하는 아날로그 입력을 읽어 변환 맵(⑤)으로 전류 값으로 바꿉니다.None, Analog Input 0~3
㉔전압 피드백실제 용접 전압에 해당하는 아날로그 입력을 읽어 변환 맵(⑤)으로 전압 값으로 바꿉니다.None, Analog Input 0~3

용접기 준비 신호를 제외하고, None을 고른 신호는 읽지 않고 꺼진 값(전류·전압은 0)으로 처리합니다.

용접 하드웨어 (④) ​

사용하는 용접기의 종류를 고릅니다. 아래는 아직 아무것도 바꾸지 않은 상태입니다. 장치 ID가 Miller M.Bus일 때 이 값들이 연결 시 용접기로 전달됩니다.

번호항목선택지
㉕프로세스 타입CV MIG, Pulse, HD MIG, RMD
㉖와이어 타입Steel (ER70X), Metal (EXXC), Flux (EXXT), AL (4XXX), AL (4943), AL (5XXX), SS (ER3XX), SS (ER4XX)
㉗와이어 크기0.8mm, 0.9mm, 1.0mm, 1.2mm (0.045), 1.2mm (3/64), 1.4mm, 1.6mm, 2.0mm, 2.4mm
㉘가스 타입100% Ar, 98% Ar+2% CO2, 95% Ar+5% CO2, 90% Ar+10% CO2, 85% Ar+15% CO2, 80% Ar+20% CO2, 75% Ar+25% CO2, 100% CO2, 98% Ar+2% O2, 95% Ar+5% O2, 100% He, 75% He+25% Ar, 50% He+50% Ar, 25% He+75% Ar, 81% Ar+18% He+1% CO2, 66% Ar+33% He+1% CO2, 90% He+7.5% Ar+2.5% CO2

용접 변환 맵 (⑤) ​

변환 맵은 전류·전압 값과 **아날로그 입출력 전압(V)**의 대응표입니다. 용접 전류와 용접 전압에 각각 표가 하나씩 있고, 줄마다 값(왼쪽 입력칸)과 그에 대응하는 출력(V)(오른쪽 입력칸)을 입력합니다. 아래는 전류·전압 맵에 한 줄씩 추가한 상태입니다.

번호항목설명
㉙전류 맵 추가용접 전류 표에 값이 0인 줄을 추가합니다.
㉚전류 (A) 입력칸변환할 값입니다.
㉛출력 (V) 입력칸㉚의 값에 대응하는 아날로그 전압입니다.
㉜삭제 버튼그 줄을 삭제합니다.
㉝전압 맵 추가용접 전압 표에 줄을 추가합니다. 입력 방식은 전류 표와 같습니다.

변환 방식 ​

  • 값이 줄과 줄 사이에 있으면 두 줄 사이를 직선으로 보간한 출력을 사용합니다.
  • 값이 첫 줄보다 작거나 마지막 줄보다 크면 가장 가까운 끝 줄의 출력을 사용합니다.
  • 줄이 하나뿐이면 항상 그 줄의 출력을 사용합니다. 줄이 없으면 0을 사용합니다.
  • 입력 포트로 읽는 전류·전압 피드백(㉓, ㉔)은 같은 표를 반대로 적용해 출력(V)에서 값을 구합니다.
  • 줄은 입력한 순서와 관계없이 저장하면 값 기준 오름차순으로 정렬되어 다시 표시됩니다.

줄은 10개까지 저장됩니다

화면에서는 전류·전압 각각 16줄까지 추가할 수 있지만, 10줄을 넘으면 저장되지 않고 "Set Welding Error" 오류 창이 표시됩니다. 전류와 전압 표 각각 10줄 이하로 입력하세요.

직접 해 보기 ​

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

장치 ID를 I/O Signal로 고르고 아크 발생 신호 포트와 프로세스 타입을 정한 뒤, 전류 맵에 한 줄을 추가해 저장하는 과정입니다.

  1. 1

    용접 장치 카드

    가장 위의 용접 장치 옵션 설정 카드에서 로봇이 용접기와 통신하는 방식(장치 ID)과, 통신 장치의 IP·포트를 정합니다.

  2. 2

    장치 ID 목록 열기

    장치 ID 선택 상자를 누르면 None, I/O Signal, Miller M.Bus, Aotai M.Bus 목록이 열립니다.

  3. 3

    I/O Signal 고르기

    목록에서 I/O Signal을 누릅니다. 용접기와 컨트롤 박스의 입출력 신호로 연결하는 방식입니다.

  4. 4

    I/O Signal을 고르면

    I/O Signal을 고르면 로봇이 컨트롤 박스의 입출력 신호로 용접기와 연결합니다. 이때 출력·입력 카드에서 고른 포트가 사용되며, 장치 IP와 포트는 M.Bus 통신 방식에서 쓰이므로 이 방식에서는 쓰이지 않습니다. 저장하기 전에는 적용되지 않습니다.

  5. 5

    용접 출력 카드

    용접 출력 옵션 설정 카드에서 로봇이 용접기로 보내는 신호(아크 발생, 접촉, 가스 발생, 와이어 인칭·재인칭)와 전류·전압 설정값을 내보낼 포트를 정합니다.

  6. 6

    아크 발생 신호 목록 열기

    아크 발생 신호 선택 상자를 누르면 None과 Digital Output 0~15 목록이 열립니다.

  7. 7

    Digital Output 0 고르기

    목록에서 Digital Output 0을 누릅니다. 아크를 발생시킬 때 이 디지털 출력이 켜집니다.

  8. 8

    Digital Output 0을 고르면

    아크 발생 신호를 Digital Output 0으로 정하면 아크 용접을 하는 동안 컨트롤 박스의 디지털 출력 0이 켜지고, 그 외에는 꺼집니다. None으로 두면 이 신호는 내보내지 않습니다. 접촉·가스·인칭·재인칭 신호도 같은 방식으로 포트를 정합니다.

  9. 9

    용접 입력 카드

    용접 입력 옵션 설정 카드에서 용접기가 로봇으로 돌려주는 신호(용접기 준비, 아크·접촉·가스·송급기 피드백, 용접기 에러)와 전류·전압 피드백을 읽을 포트를 정합니다.

  10. 10

    용접 하드웨어 카드

    용접 하드웨어 옵션 설정 카드에서 사용하는 용접 프로세스 타입, 와이어 타입과 크기, 가스 타입을 고릅니다.

  11. 11

    프로세스 타입 목록 열기

    프로세스 타입 선택 상자를 누르면 CV MIG, Pulse, HD MIG, RMD 목록이 열립니다.

  12. 12

    Pulse 고르기

    목록에서 Pulse를 누릅니다.

  13. 13

    Pulse를 고르면

    프로세스 타입이 Pulse로 정해집니다. 이 값은 장치 ID가 Miller M.Bus일 때 용접기와 연결되는 순간 용접기로 전달되며, 와이어 타입·크기와 가스 타입도 같은 방식으로 전달됩니다.

  14. 14

    용접 변환 맵 카드

    용접 변환 맵 설정 카드에서 용접 전류(A)·전압 값과 아날로그 포트로 내보내는 출력(V)의 대응을 표로 정합니다.

  15. 15

    전류 맵 추가

    용접 전류 영역의 전류 맵 추가를 누르면 전류(A)와 출력(V) 입력칸이 있는 한 줄이 추가됩니다.

  16. 16

    전류·출력 값 입력

    추가된 줄의 전류(A) 입력칸과 출력(V) 입력칸에 값을 입력합니다. 예를 들어 100과 5를 입력하면 전류 100A에 출력 5V를 대응시킵니다.

  17. 17

    이렇게 입력하면

    전류 100A에 출력 5V를 입력하면, 줄이 하나뿐이므로 어떤 전류에서도 이 줄의 출력(5V)을 사용합니다. 줄을 더 추가하면 줄 사이는 직선으로 보간하고, 첫 줄보다 작거나 마지막 줄보다 큰 값은 끝 줄의 출력을 사용합니다.

  18. 18

    저장

    화면 위쪽의 저장을 누릅니다. 저장하기 전에는 고른 값이 적용되지 않으며, 초기화를 누르면 저장된 값으로 되돌아갑니다. 다섯 카드의 값이 한꺼번에 저장됩니다.

  19. 19

    저장된 값 확인

    저장한 값이 그대로 표시되고, 화면의 값이 저장된 값과 같아지므로 초기화 버튼이 눌리지 않는 상태가 됩니다.

저장에 실패하면
