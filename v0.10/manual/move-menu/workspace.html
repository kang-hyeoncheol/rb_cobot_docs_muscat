워크스페이스 ​

동작 화면의 3D 장면에 놓을 오브젝트(도형·파일)를 구성하고 저장하는 메뉴입니다.

화면에서 파란 테두리로 표시한 곳입니다. 오른쪽 메뉴의 항목을 누르면 옆에 이 패널이 열립니다.

직접 해 보기 ​

실습은 작업별로 나뉘어 있고 서로 이어지지 않습니다. 필요한 것을 골라 바로 시작할 수 있으며, 각 실습은 소개 → 직접 해 보기 순서로 진행합니다. 소개 단계에서는 설명을 확인하고, 직접 해 보기 단계에서 안내된 부분을 조작하세요. 다시 하기를 누르면 해당 실습이 처음 상태로 초기화됩니다.

실습시작 상태하는 일
새로 만들기워크스페이스가 없음이름을 입력해 빈 워크스페이스 만들기
도형 추가Welding cell이 열려 있음직육면체 추가하기
위치·크기 바꾸기Welding cell이 열려 있음도형의 X 위치와 SX 크기 바꾸기
목록 관리Welding cell이 열려 있음도형 숨기기와 다시 표시
저장·불러오기Welding cell이 열려 있음위치를 바꾸고 저장한 뒤 닫았다가 다시 불러오기
자유 실습Welding cell이 열려 있음배운 기능을 자유롭게 사용

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

패널 화면 ​

위 화면은 가상 로봇(데모)에서 캡처한 것이라 값은 실제 로봇과 다를 수 있습니다.

처음에는 새로 만들기와 불러오기 두 버튼만 보입니다. 패널 위쪽에는 베이스·툴 탭이 있고, 툴이 여러 개인 로봇에서는 탭 이름이 오른쪽 툴·왼쪽 툴·툴 N처럼 나뉩니다.

워크스페이스 열기 ​

  • 새로 만들기: 이름을 입력해 새 워크스페이스를 만듭니다("새 워크스페이스 만들기" 창).
  • 불러오기: 저장된 워크스페이스를 고릅니다. 저장하지 않은 변경 사항이 있는 상태에서 다른 워크스페이스를 열면 변경 사항이 사라진다는 확인 창이 뜹니다.

워크스페이스를 연 뒤 ​

버튼 위치와 상태 표시, 목록 선택 모드, 속성 입력, 3D 편집 도구는 편집 화면 구성에서 번호가 있는 화면과 함께 설명합니다.

영역설명
이름·저장 상태워크스페이스 이름과 저장됨 / 저장 안 됨 표시. 이름은 바꿀 수 있습니다.
되돌리기 · 다시 실행편집 내용을 되돌리거나 다시 적용합니다.
워크스페이스 메뉴새로 만들기, 불러오기, 이름 변경, 사본 만들기, 삭제, 오브젝트 전체 삭제, 마지막 저장 상태로 되돌리기
오브젝트 추가직육면체, 원기둥, 구, 불러온 파일을 더합니다.
오브젝트 리스트추가한 오브젝트 목록. 항목별로 씬에서 숨기기/다시 표시, 삭제를 하고, 선택 모드에서 여러 개를 한꺼번에 숨기거나 삭제합니다.
오브젝트 속성선택한 오브젝트의 위치·회전·크기를 수치로 입력하고 초기화로 되돌립니다. 3D 편집 도구는 오브젝트 하나를 선택했을 때 3D 화면 왼쪽에 나타납니다.

제한과 안내 ​

  • 도형은 최대 5개까지 추가할 수 있습니다.
  • 불러온 파일은 워크스페이스에 1개만 둘 수 있습니다. 새 파일을 넣으면 기존 파일을 교체할지 묻습니다.
  • STEP 형식(.stp, .step) 파일은 불러오는 데 시간이 오래 걸릴 수 있다는 안내가 표시됩니다.
  • 이름에는 공백이나 # ? & % 문자를 쓸 수 없습니다.
  • 저장하지 않은 변경 사항이 있는 채로 닫으면 저장하지 않고 닫기를 묻습니다.

예제: 작업대와 원기둥 만들기 ​

베이스 탭의 demo_cell 워크스페이스에 작업대와 원기둥을 배치하는 예제입니다. 새로 만들기 실습에서 demo_cell을 만든 뒤 이어서 따라 해 볼 수 있습니다. 자유 실습은 Welding cell이 열려 있는 상태로 시작하므로, 1번에서 새로 만들거나 열려 있는 워크스페이스에 도형을 더하며 연습하세요.

1. 빈 워크스페이스 만들기 ​

  1. 새로 만들기를 누릅니다. 이미 다른 워크스페이스를 편집 중이라면 상단 워크스페이스 메뉴에서 새로 만들기를 선택합니다.
  2. 이름에 demo_cell을 입력하고 확인을 누릅니다.
  3. 상단 이름이 demo_cell인지 확인합니다. 새 워크스페이스에는 직접 사용할 도형을 추가합니다.

demo_cell이 이미 열려 있다면 이 단계는 건너뜁니다. 다른 워크스페이스를 새로 만들 때는 기존 이름과 구분되는 이름을 입력하세요.

2. 직육면체로 작업대 추가하기 ​

이미 추가한 직육면체가 있다면 그 항목을 선택하고 3번부터 진행합니다.

  1. 오브젝트 리스트 오른쪽 **+ (오브젝트 추가)**를 누릅니다.
  2. 직육면체를 누릅니다. 목록에 새 항목이 추가됩니다.
  3. 목록의 도형을 선택하고 아래 오브젝트 속성의 입력칸을 눌러 다음 값을 입력합니다. 키보드로 입력한 뒤 Enter를 누르세요. 화면 숫자 키패드를 사용한다면 Set으로 적용합니다.
속성X / RX / SXY / RY / SYZ / RZ / SZ
위치 (mm)5000150
회전 (°)000
크기 (mm)300300300
  1. 항목 오른쪽 **⋮ (오브젝트 메뉴)**에서 이름 변경을 선택합니다. Worktable을 입력하고 Enter를 누릅니다.
  2. 3D 화면에서 작업대가 보이는지 확인합니다. 드래그로 시점을 돌리고 마우스 휠로 확대·축소할 수 있습니다.

위치·크기는 mm, 회전은 ° 단위입니다. 크기 SX·SY·SZ에는 배율이 아니라 원하는 치수를 입력합니다. 이 예제의 수치는 실습용 배치입니다.

3. 원기둥 추가하고 개별 편집하기 ​

  1. 다시 + → 원기둥을 선택합니다.
  2. 추가된 원기둥을 선택하고 다음 값을 입력합니다.
속성X / RX / SXY / RY / SYZ / RZ / SZ
위치 (mm)500300100
회전 (°)000
크기 (mm)100100200
  1. 이름을 Post로 바꿉니다. 목록에서 Worktable과 Post를 번갈아 선택해 각 도형의 속성을 확인합니다.

속성의 초기화는 선택한 도형의 위치·회전을 0으로, 크기를 기본 치수로 되돌립니다. 워크스페이스 전체를 지우는 기능과는 다릅니다.

4. 숨기기·삭제·되돌리기 연습하기 ​

해볼 작업조작확인할 결과
잠깐 숨기기Post의 ⋮ → 씬에서 숨기기목록에는 남고 3D 화면에서 숨겨집니다.
다시 표시하기같은 항목의 ⋮ → 씬에 다시 표시숨긴 도형이 다시 보입니다.
도형 하나 삭제하기Post의 ⋮ → 오브젝트 삭제목록과 3D 화면에서 제거됩니다.
삭제 취소하기패널 상단 되돌리기삭제한 도형이 돌아옵니다.
삭제 다시 적용하기패널 상단 다시 실행취소했던 삭제가 다시 적용됩니다.
여러 항목 관리하기선택을 누르고 항목을 체크선택한 항목들을 함께 숨기거나 삭제할 수 있습니다. 선택 취소로 종료합니다.

예제를 계속하려면 되돌리기로 작업대와 원기둥이 모두 남아 있는 상태로 만드세요. 되돌리기·다시 실행으로 고른 최종 상태는 저장을 눌러 저장하세요.

5. 저장하고 다시 열기 ​

  1. 상단 저장을 누릅니다. 자동저장이 먼저 끝났다면 저장 버튼은 비활성화되어 있을 수 있습니다.
  2. 저장 직후의 저장됨 표시를 확인합니다. 이 표시는 잠시 후 사라집니다. 저장 안 됨이 남아 있다면 변경 사항을 다시 확인합니다.
  3. 닫기 → 불러오기를 누릅니다.
  4. 목록에서 demo_cell을 선택하고 확인을 누릅니다. 항목을 더블클릭해 바로 열 수도 있습니다. Worktable과 Post의 위치·크기가 유지되는지 확인합니다.

편집 내용은 자동으로 저장되며 저장 버튼으로 즉시 저장할 수도 있습니다. 이 페이지의 실습 데이터는 실습을 다시 시작하거나 새로 열면 초기화됩니다.

워크스페이스 전체 관리 ​

패널 상단 워크스페이스 메뉴에서 이름 변경·사본 만들기·전체 삭제 등을 수행합니다. 메뉴별 동작과 비활성화 조건은 편집 화면 구성의 워크스페이스 메뉴를 참고하세요.

이 실습에서는 직육면체·원기둥·구를 사용합니다. 불러온 파일을 통한 파일 업로드는 실습에서 지원하지 않습니다.
