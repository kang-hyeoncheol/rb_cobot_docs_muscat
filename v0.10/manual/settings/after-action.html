After Action ​

After Action은 로봇에서 특정 일이 끝난 뒤에 사용자 스크립트를 자동으로 실행하도록 정하는 설정입니다. 시점마다 "아무것도 하지 않음" 또는 "사용자 스크립트 0~15 중 하나 실행"을 고를 수 있습니다.

이 문서에서는 설정 > 일반 > After Action 화면에서 다음을 해 봅니다.

  • 16가지 시점과 현재 설정 한눈에 보기
  • 시점을 골라 실행할 스크립트 정하기
  • 저장하고 카드에서 결과 확인하기

화면 구성 ​

왼쪽 설정 메뉴의 일반 > After Action을 누르면 나타나는 화면입니다. 아직 아무것도 바꾸지 않은 상태이며 첫 번째 시점(After System Boot)이 선택되어 있습니다.

번호영역역할
①시점 탭시점 이름이 가로로 나열됩니다. 누르면 해당 카드가 선택됩니다. 기본값이 아닌 동작이 지정된 시점은 노란색으로 표시됩니다.
②카드 목록시점마다 카드가 하나씩 있고, 동작 종류에 현재 설정된 동작이 표시됩니다. 카드를 눌러 선택할 수도 있습니다. 기본값이 아닌 동작은 노란색으로 표시됩니다.
③설정 영역선택한 시점의 이름과 동작을 바꾸는 영역입니다. 아래에서 자세히 설명합니다.

설정 영역(③)의 구성 ​

설정 영역을 확대한 화면입니다. 아래는 After Servo On의 동작을 Run User Script 0으로 골랐지만 아직 저장하지 않은 상태입니다.

번호항목설명
④After Action 선택 상자Do nothing(아무것도 하지 않음) 또는 Run User Script 0~15 중에서 고릅니다. 목록의 첫 항목(Do nothing)이 아닌 값을 고르면 선택 상자의 글자가 노란색으로 바뀝니다.
⑤초기화고르기만 하고 저장하지 않은 값을 저장된 값으로 되돌립니다. 고른 값이 저장된 값과 같으면 눌리지 않습니다.
⑥저장선택한 동작을 해당 시점에 저장합니다. 저장해야 설정이 적용됩니다.

기본값이 아닌 값 표시 ​

설정 화면에는 기본값이 아닌 값을 노란색으로 표시해 한눈에 구별하게 하는 기능이 있습니다. (밝은 테마에서는 주황색으로 보입니다.) After Action에서는 아래 세 곳에 적용됩니다. 기본값은 Do nothing입니다.

번호위치표시
①시점 탭기본값이 아닌 동작이 저장된 시점의 이름이 노란색이 됩니다.
②카드의 동작 종류저장된 동작이 Do nothing이 아니면 노란색이 되고, 카드 글자도 굵게 표시됩니다.
③선택 상자고른 값이 Do nothing이 아니면 노란색입니다. 저장 전에도 바뀝니다.

다른 설정 화면에서는 다음 경우에 노란색으로 표시됩니다.

화면노란색으로 표시되는 경우
After Action동작이 Do nothing이 아닐 때 (시점 탭·카드·선택 상자)
사용자 스크립트카드의 스크립트가 비어 있을 때(no set script, 다른 화면과 반대). 스크립트가 있는 항목의 탭은 노란색으로 표시됩니다.
디지털 입력·출력 기능카드의 기능이 지정되어 있을 때
디지털 입력 필터지연 값이 1이 아닐 때 (카드·탭)

시점과 동작 ​

시점 ​

시점은 "무슨 일이 끝난 뒤에 실행할 것인가"를 정합니다. 시점마다 따로 동작을 지정합니다.

시점실행되는 때
After System Boot제어 시스템이 시작된 뒤
After Servo On서보 켜기에 성공한 뒤
After Real Mode On서보 켜기에 성공한 뒤 Real Mode(실제 로봇 모드)가 켜져 있을 때
After Simul Mode OnSimul Mode(시뮬레이션 모드)를 켠 뒤
After Arm DC Power On로봇 팔의 DC 전원을 켠 뒤
After Arm DC Power Off로봇 팔의 DC 전원을 끈 뒤
After Program Start프로그램을 시작할 때
After Program Stop프로그램이 끝날 때
After Direct Teaching On직접 교시를 켠 뒤
After Direct Teaching Off직접 교시를 끈 뒤
After Collision Occur충돌이 발생한 뒤
After Collision Reset충돌 상태를 해제(리셋)한 뒤
After Pause일시 정지한 뒤
After Resume일시 정지한 것을 다시 시작한 뒤
After Move Start이동을 시작한 뒤
After Move Done이동을 마친 뒤

동작 ​

선택의미
Do nothing아무것도 하지 않습니다. 기본값입니다.
Run User Script N (N = 0~15)사용자 스크립트 설정에서 N번에 저장해 둔 명령을 실행합니다. 그 번호에 저장된 명령이 없으면 아무 일도 일어나지 않습니다.

직접 해 보기 ​

가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

시점 하나에 동작을 지정하는 과정입니다. 예시는 After Servo On에 Run User Script 0을 지정합니다.

  1. 1

    시점 고르기

    카드 목록에서 After Servo On 카드를 누릅니다. 카드가 선택되고 오른쪽 설정 영역의 제목이 After Servo On으로 바뀝니다.

  2. 2

    설정 영역

    오른쪽 설정 영역에는 선택한 시점의 이름과 현재 동작이 표시됩니다. 처음에는 Do nothing이라 아무 동작도 하지 않습니다.

  3. 3

    동작 목록 열기

    After Action 선택 상자를 누르면 Do nothing과 Run User Script 0~15 목록이 열립니다.

  4. 4

    스크립트 고르기

    목록에서 Run User Script 0을 누릅니다. 사용자 스크립트 0번에 저장해 둔 명령이 실행되도록 고르는 것입니다.

  5. 5

    저장하기

    저장을 누릅니다. 저장하기 전에는 고른 값이 적용되지 않으며, 초기화를 누르면 고르기 전 값으로 돌아갑니다.

  6. 6

    저장된 값 확인

    After Servo On 카드의 동작 종류가 Run User Script 0으로 바뀌고, 기본값(Do nothing)이 아닌 값이라 강조색으로 표시됩니다.

여러 시점 설정하기

시점마다 따로 저장합니다. 다른 시점을 고르면 선택 상자에 그 시점에 저장된 값이 나타납니다.

저장에 실패하면

저장하지 못하면 "Set After Action Error" 창이 표시되고 카드의 값은 바뀌지 않습니다.
