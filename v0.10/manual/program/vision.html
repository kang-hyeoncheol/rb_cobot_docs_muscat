비전 ​

비전은 프로그램에서 3D 비전 카메라(비전 서버)와 통신하는 명령입니다. 카메라에 연결하고, 촬영을 요청하고, 인식한 물체의 위치를 읽어 오는 일을 프로그램 안에서 할 수 있습니다. 읽은 위치는 변수에 저장되므로 뒤의 동작 명령에서 쓸 수 있습니다.

이 문서에서는 프로그램 화면에서 다음을 해 봅니다.

  • 비전 명령으로 카메라 연결 만들기
  • 두 번째 비전 명령으로 촬영하고 물체 위치 읽기
  • 연결할 수 있는 비전 시스템 확인하기

실습에서 확인할 수 있는 것

실습 화면에는 카메라가 없어 설정만 해 볼 수 있습니다. 프로그램을 실행했을 때의 카메라 응답은 확인할 수 없습니다.

비전 시스템 ​

설정 화면의 옵션에서 연결할 비전 시스템을 고릅니다. 고른 시스템에 맞는 설정 항목이 아래에 나타납니다.

옵션기본 포트하는 일(함수 목록에서 고름)
MechMind 3D50000연결 생성, 레시피 설정, 트리거, 트리거 & 자세 읽기, 자세 읽기
Photoneo11003연결 생성, 초기화, 스캔, 오브젝트 위치 조회, 궤적 조회, 솔루션 변경·시작·정지·조회, 궤적 이동
PICKIT 3D50연결 생성, 로봇 자세 업데이트, 모드 확인, 시스템 종료, 캘리브레이션 플레이트 찾기·설정·계산·검증, 객체 탐색, 재시도 객체 탐색, 다음 객체, 이미지 캡처·처리, 피킹 포인트 데이터 가져오기, 셋업 및 제품 설정, 실린더 치수 설정, 활성 셋업·제품 저장, 배경 생성, 스냅샷 저장

이 문서는 처음 골라져 있는 MechMind 3D를 자세히 설명합니다. 다른 시스템도 같은 구조입니다. 목표 서버 IP 주소와 포트 번호, 함수 목록에서 고르는 기능, 기능별 설정 영역으로 이루어집니다.

MechMind 3D 설정 화면 ​

함수 목록이 연결 생성일 때의 화면입니다. 목표 서버 IP 주소에 192.168.0.10, 타임 아웃에 10을 입력한 상태입니다.

번호항목설명
①옵션연결할 비전 시스템(MechMind 3D·Photoneo·PICKIT 3D)입니다.
②목표 서버 IP 주소카메라(비전 서버)의 IP 주소입니다. 네 칸에 나누어 입력하며 모두 입력해야 저장할 수 있습니다.
③목표 서버 포트 번호MechMind 3D는 50000으로 정해져 있어 바꿀 수 없습니다.
④함수 목록 (코드)이 명령이 하는 일입니다. 연결 생성(99), 레시피 설정(3), 트리거(1), 트리거 & 자세 읽기(0), 자세 읽기(2) 중에서 고릅니다.
⑤타임 아웃 (초)카메라의 응답을 기다리는 시간입니다.
⑥설치 위치카메라를 로봇 손에 달았는지(Eye In Hand), 로봇 밖에 고정했는지(Eye To Hand)입니다.
⑦Project ID카메라 소프트웨어의 프로젝트 번호입니다. 비워 둘 수 있고, 입력하면 정수여야 합니다("Integer only").
⑧실패 처리 방식카메라와의 통신이 실패했을 때의 동작입니다. 무시 후 진행, 즉시 중단, 사용자 확인 중에서 고르며 처음에는 무시 후 진행입니다.
⑨닫기설정 화면을 닫습니다. 저장하지 않은 변경이 있으면 저장하지 않고 닫을지 묻습니다.
⑩저장설정을 적용합니다. 트리의 비전 옆에 MechMind Interface - [Create Connection] 192.168.0.10:50000처럼 표시됩니다.

함수 목록별 설정 ​

함수 목록을 바꾸면 ⑦ 아래의 설정 영역이 바뀝니다.

함수아래 설정 영역의 항목하는 일
연결 생성Project ID, 실패 처리 방식카메라에 연결합니다. 같은 태스크에서 다시 연결 생성을 실행하면 이전 연결을 끊고 새로 연결합니다.
레시피 설정Project ID, Recipe ID, 실패 처리 방식프로젝트에서 사용할 레시피를 바꿉니다.
트리거Project ID, 예상 수, 실패 처리 방식촬영과 인식을 요청합니다. 예상 수는 인식하려는 물체의 예상 개수입니다. 결과 위치는 자세 읽기로 따로 읽습니다.
트리거 & 자세 읽기Project ID, 반환 변수명, 실패 처리 방식촬영·인식을 요청하고 인식한 물체의 위치 목록을 한 번에 읽어 반환 변수명의 변수에 저장합니다.
자세 읽기Project ID, 반환 변수명, 실패 처리 방식새로 촬영하지 않고 가장 최근 트리거의 결과 위치를 읽어 변수에 저장합니다.

읽은 위치는 [x, y, z, rx, ry, rz] 형태의 값을 담은 목록입니다. 촬영할 때 설치 위치가 Eye In Hand이면 로봇의 현재 자세를 카메라 소프트웨어에 함께 보내 위치를 보정하고, Eye To Hand이면 로봇 자세를 보내지 않습니다.

연결 생성 먼저

트리거·자세 읽기 같은 함수는 앞에서 연결 생성이 실행되어 연결되어 있어야 동작합니다. 연결 생성이 아닌 함수를 고르면 목표 서버 IP 주소·포트·타임 아웃·설치 위치를 바꿀 수 없고, 앞의 연결 생성 비전 명령에서 정한 값을 따릅니다.

읽기 설정 ​

함수 목록을 트리거 & 자세 읽기로 고른 화면의 읽기 설정 영역입니다.

번호항목설명
①Project ID읽을 프로젝트 번호입니다. 비워 둘 수 있습니다.
②반환 변수명읽은 위치 목록을 저장할 변수 이름입니다. 비워 두면 저장할 수 없습니다.
③실패 처리 방식연결 생성과 같습니다.

직접 해 보기 ​

비전 명령을 두 개 만들어 카메라 연결 생성과 물체 위치 읽기를 설정해 봅니다. 실습에는 실제 카메라가 없으며 프로그램을 실행하지 않습니다. 실습은 두 가지이며 어느 쪽부터 해도 되고, 앞의 실습을 하지 않아도 시작할 수 있습니다. 실습을 다시 시작하면 바꾼 값은 처음 상태로 돌아갑니다.

카메라 연결 만들기 ​

비전을 추가하고 MechMind 3D의 연결 생성을 설정하는 과정입니다.

  1. 트리의 빈 영역을 눌러 위치를 정하고 편집 아이콘으로 명령어 목록을 연 뒤 비전을 추가합니다.
  2. 트리에서 비전을 눌러 설정 화면을 열고, MechMind 3D의 연결 생성 설정을 확인합니다.
  3. 목표 서버 IP 주소의 네 칸에 192, 168, 0, 10을, 타임 아웃에 10을 입력합니다. 입력한 값이 안내와 같아야 다음으로 넘어갈 수 있으며, 건너뛰면 자동으로 입력됩니다.
  4. 저장을 누르면 트리의 비전 옆에 [Create Connection]과 주소가 표시됩니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    넣을 위치 고르기

    프로그램 트리에서 명령을 넣을 위치의 빈 영역을 누릅니다.

  2. 2

    명령어 목록 열기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 명령어 목록이 열립니다.

  3. 3

    비전 고르기

    매니퓰레이트 명령어에서 비전을 누릅니다. 트리에 비전 명령이 추가됩니다.

  4. 4

    트리에 추가된 비전

    트리에 비전 명령이 추가됩니다.

  5. 5

    비전 열기

    트리에서 비전을 누르면 오른쪽에 설정 화면이 열립니다.

  6. 6

    비전 설정 화면

    옵션에서 연결할 비전 시스템을 고릅니다. MechMind 3D, Photoneo, PICKIT 3D 중 하나이며, 고른 시스템에 맞는 설정 항목이 아래에 나타납니다. 처음에는 MechMind 3D가 골라져 있습니다.

  7. 7

    MechMind 3D 인터페이스

    MechMind 3D 인터페이스 영역에서는 카메라(비전 서버)의 목표 서버 IP 주소와 포트 번호, 함수 목록(코드), 타임 아웃(초), 설치 위치를 정합니다. 처음 함수는 연결 생성이며, IP·타임 아웃·설치 위치는 연결 생성에서만 정할 수 있습니다.

  8. 8

    IP 주소 입력

    목표 서버 IP 주소의 네 칸에 주소를 나누어 입력합니다. 예에서는 192, 168, 0, 10 을 입력합니다. 포트 번호는 MechMind 3D에서 50000으로 정해져 있습니다.

  9. 9

    타임 아웃 입력

    타임 아웃(초)에 카메라의 응답을 기다릴 시간을 입력합니다. 예에서는 10 을 입력합니다.

  10. 10

    정한 값 확인

    카메라 주소를 192.168.0.10, 타임 아웃을 10초로 정합니다. 포트 번호는 MechMind 3D에서 50000으로 정해져 있습니다. 저장하기 전에는 적용되지 않습니다.

  11. 11

    연결 생성 저장

    저장을 누르면 설정이 적용됩니다. 트리의 비전 옆에 [Create Connection]과 주소가 표시됩니다. 실패 처리 방식은 처음 값(무시 후 진행)을 그대로 씁니다.

  12. 12

    저장된 연결 확인

    트리의 비전 옆에 [Create Connection]과 IP 주소·포트가 표시됩니다. 프로그램을 실행하면 이 지점에서 카메라에 연결합니다.

물체 위치 읽기 설정하기 ​

연결 생성이 들어 있는 프로그램에 비전을 한 번 더 추가해 물체 위치를 읽도록 설정하는 과정입니다.

  1. 트리의 빈 영역을 눌러 위치를 정하고 편집 아이콘으로 명령어 목록을 연 뒤 비전을 한 번 더 추가합니다.
  2. 새로 추가된 비전의 설정 화면을 열고, 함수 목록을 트리거 & 자세 읽기로 바꿉니다.
  3. 반환 변수명에 poses를 입력하고 저장하면 두 번째 비전 옆에 [Trigger & Read Pose]가 표시됩니다.

사용 방법 ​

  1. 1

    넣을 위치 고르기

    프로그램 트리에서 명령을 넣을 위치의 빈 영역을 누릅니다.

  2. 2

    명령어 목록 열기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 명령어 목록이 열립니다.

  3. 3

    비전 한 번 더 추가

    같은 방법으로 비전 명령을 하나 더 추가합니다. 카메라에서 물체의 위치를 읽는 명령으로 만듭니다.

  4. 4

    두 번째 비전 열기

    새로 추가된 두 번째 비전을 눌러 설정 화면을 엽니다.

  5. 5

    함수 목록 열기

    함수 목록(코드) 선택 상자를 누르면 연결 생성, 레시피 설정, 트리거, 트리거 & 자세 읽기, 자세 읽기 목록이 열립니다.

  6. 6

    트리거 & 자세 읽기 고르기

    목록에서 트리거 & 자세 읽기를 누르면 아래에 읽기 설정이 나타납니다. IP 주소·포트·타임 아웃·설치 위치는 앞의 연결 생성 설정을 따라 바꿀 수 없게 됩니다.

  7. 7

    읽기 설정

    읽기 설정에서는 Project ID, 읽은 위치를 저장할 변수 이름, 실패했을 때의 처리 방식을 정합니다.

  8. 8

    반환 변수명 입력

    반환 변수명에 읽은 위치를 저장할 변수 이름을 입력합니다. 예에서는 poses 를 입력합니다. 비워 두면 저장할 수 없습니다.

  9. 9

    반환 변수 확인

    읽은 위치 목록은 반환 변수명에 입력한 poses 변수에 저장됩니다. 위치는 [x, y, z, rx, ry, rz] 형태의 값입니다. 저장하기 전에는 적용되지 않습니다.

  10. 10

    실패 처리 방식

    실패 처리 방식은 카메라와의 통신이 실패했을 때 프로그램이 어떻게 할지 정합니다. 무시 후 진행, 즉시 중단, 사용자 확인 중에서 고르며, 처음에는 무시 후 진행입니다.

  11. 11

    읽기 설정 저장
