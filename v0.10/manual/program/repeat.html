반복 ​

반복은 안에 넣은 명령을 여러 번 되풀이해 실행하는 명령입니다. 같은 작업을 정해진 횟수만큼 하거나, 조건이 참인 동안 계속하고 싶을 때 사용합니다. 반복을 중간에 끝내려면 반복중단을 함께 씁니다.

이 문서에서는 프로그램 화면에서 다음을 해 봅니다.

  • 반복을 추가하고 반복 횟수 정하기
  • While·Do While 조건으로 반복하기
  • 반복 안에 반복중단 넣기

준비

프로그램이 하나 열려 있어야 합니다. 프로그램이 없으면 새 프로그램 만들기를 먼저 따라 합니다.

반복 추가하기 ​

공통 명령어에서 반복을 누르면 먼저 반복 횟수를 정하는 창이 나타납니다. 정하고 나면 트리에 반복이 추가되고, 그 아래에 반복할 명령을 넣는 빈 영역이 생깁니다.

번호항목설명
①직접 입력 / 무한 반복직접 입력은 횟수를 숫자로 적습니다. 무한 반복을 고르면 횟수 입력이 꺼지고 멈출 때까지 계속 반복합니다.
②횟수 입력반복할 횟수입니다. 기본값은 1이며 100을 넘는 값은 설정할 수 없습니다.
③취소반복을 추가하지 않고 창을 닫습니다.
④설정정한 횟수로 반복을 추가합니다. 트리에 반복 (3 Times)처럼 표시됩니다.

설정 화면 ​

트리의 반복을 누르면 오른쪽에 설정 화면이 열립니다. 아래는 횟수 3으로 추가한 직후의 화면입니다.

번호항목설명
①반복 횟수정한 횟수만큼 반복합니다.
②While 방식조건이 참인 동안 반복합니다. 조건은 반복할 때마다 먼저 확인하므로, 처음부터 거짓이면 한 번도 실행하지 않습니다.
③Do While 방식먼저 한 번 실행한 뒤 조건을 확인해, 참이면 다시 반복합니다. 조건이 처음부터 거짓이어도 한 번은 실행합니다.
④직접 입력 / 무한 반복반복 횟수 방식에서 횟수 입력 방식을 고릅니다.
⑤횟수 / 조건 입력반복 횟수 방식에서는 횟수(최대 100), While·Do While 방식에서는 조건식을 입력합니다.
⑥닫기설정 화면을 닫습니다. 저장하지 않은 변경이 있으면 저장하지 않고 닫을지 묻습니다.
⑦저장정한 방식을 적용하고 설정 화면을 닫습니다.

반복 횟수 방식에서 횟수에 음수를 입력하면 무한 반복합니다. 무한 반복은 반복 안에서 반복중단을 실행하거나 프로그램을 멈출 때까지 계속됩니다.

While·Do While 방식 ​

While 방식(②)이나 Do While 방식(③)을 고르면 상태 영역이 조건 입력칸으로 바뀝니다. 조건에는 앞에서 선언한 변수를 쓸 수 있는 식을 입력합니다(예: count < 3). 아래는 While 방식에 조건을 입력한 화면입니다.

저장하면 트리의 반복 옆에 While => count < 3(Do While은 Do While => ...)처럼 표시됩니다.

반복중단 ​

반복중단은 반복 안에서 실행하면 반복을 끝내고 반복 다음 명령으로 넘어가는 명령입니다. 반복 안의 빈 영역에 추가하며, 보통 조건문 (If) 분기 안에 넣어 "조건이 맞으면 반복을 끝낸다"는 흐름을 만듭니다.

디버그로 값 확인하기 ​

프로그램을 실행하는 동안 변수 값이 어떻게 바뀌는지 보려면 디버그 명령을 넣습니다. 디버그는 실행을 일시 중지하고 정한 변수의 값을 팝업 창에 표시합니다. 설정 화면에서 다음을 정합니다.

항목설명
옵션디버그 팝업은 변수 값을 팝업 창에 표시하고 실행을 멈춥니다. 사용자 로그는 입력한 문자열을 로그에 기록하며 실행을 멈추지 않습니다.
실행 조건항상 실행 또는 UI가 사용 중일 때만 실행을 고릅니다(디버그 팝업에서만).
정지 옵션모든 작업 또는 현재 작업을 고릅니다(디버그 팝업에서만).
변수 이름값을 보려는 변수 이름을 한 줄씩 추가합니다.

창은 Debug Variables라는 제목으로 변수 이름: 값을 한 줄씩 보여 주며, 숫자는 소수로 표시됩니다(예: 1.0). 창에서 Resume을 누르면 프로그램이 이어서 실행되고 Stop을 누르면 프로그램이 멈춥니다.

직접 해 보기 ​

예제 프로그램은 변수 count를 0으로 두고, 반복 안에서 스크립트 count += 1로 값을 올린 뒤 디버그로 count를 보여 줍니다. 실습은 세 가지이며 어느 쪽부터 해도 되고, 앞의 실습을 하지 않아도 시작할 수 있습니다. 실습을 다시 시작하면 바꾼 값은 처음 상태로 돌아갑니다.

While 조건 설정하기 ​

반복(3 Times)을 While 방식으로 바꾸고 조건을 입력해 저장하는 과정입니다.

  1. 반복은 기본적으로 정한 횟수(3 Times)만큼 실행한다는 것을 확인합니다.
  2. 반복의 설정 화면을 열어 반복 횟수·While 방식·Do While 방식의 차이를 확인하고 While 방식을 고릅니다.
  3. While 조건에 count < 3을 입력하고 저장합니다. 입력한 값이 안내와 같아야 다음으로 넘어갈 수 있으며, 공백은 다르게 입력해도 같은 값으로 봅니다. 건너뛰면 자동으로 입력됩니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    반복은 기본적으로 **정한 횟수만큼** 실행합니다. 예제의 반복은 `3 Times`라 세 번 되풀이합니다. 반복 안에는 `count`를 1 올리는 스크립트, `count`를 창으로 보여 주는 디버그, 뒤에서 반복중단을 넣을 조건문(`count == 2`)이 들어 있습니다.

  2. 2

    편집 아이콘 누르기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 편집 화면이 열립니다.

  3. 3

    반복 선택

    트리에서 반복을 누르면 선택됩니다.

  4. 4

    반복 설정 화면 열기

    선택된 반복을 한 번 더 누르면 설정 화면이 열립니다.

  5. 5

    반복 방식 세 가지

    모드에서 반복 방식을 고릅니다. **반복 횟수**는 정한 횟수만큼 반복하며 음수는 무한 반복입니다. **While 방식**은 조건이 참인 동안 반복하며, 반복할 때마다 **먼저** 조건을 확인합니다. **Do While 방식**은 먼저 한 번 실행한 뒤 조건을 확인해 참이면 다시 반복합니다.

  6. 6

    While 방식 고르기

    모드에서 While 방식을 누르면 상태에 While 조건 입력칸이 나타납니다.

  7. 7

    While 조건 입력

    While 조건에 반복을 계속할 조건을 입력합니다. 예에서는 `count < 3`을 입력해 count가 3보다 작은 동안 반복하게 합니다.

  8. 8

    저장

    저장을 누르면 조건이 적용되고 트리의 반복 옆에 `While => count < 3`이 표시됩니다.

  9. 9

    바뀐 반복 확인

    트리의 반복 옆에 `While => count < 3`이 표시됩니다. 이제 횟수가 아니라 조건으로 반복하며, 반복 안의 스크립트가 `count`를 1씩 올리므로 `count`가 3이 되면 조건이 거짓이 되어 반복이 끝납니다.

반복 실행 확인하기 ​

While 조건(count < 3)이 입력된 반복을 실행해 값이 바뀌는 것을 확인하는 과정입니다.

  1. 재생(▶)을 누르면 프로그램이 실행됩니다.
  2. 반복할 때마다 디버그 창이 떠서 count: 1.0, count: 2.0, count: 3.0이 차례로 표시되고, count가 3이 되면 반복이 끝납니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    트리의 반복 옆에 `While => count < 3`이 표시됩니다. 반복 안의 스크립트가 `count`를 1씩 올리고, 디버그가 `count`를 창으로 보여 줍니다.

  2. 2

    프로그램 실행

    재생(▶) 버튼을 누르면 프로그램이 실행되고, 지금 실행 중인 명령이 트리에 표시됩니다.

  3. 3

    첫 번째 반복의 디버그 창

    count가 0일 때 조건 `count < 3`이 참이라 반복에 들어가 count를 1로 올리고, 디버그가 **Debug Variables** 창에 `count: 1.0`을 보여 줍니다. 창이 떠 있는 동안 프로그램은 멈춰 있고, **Resume**을 누르면 이어서 실행하며 **Stop**을 누르면 프로그램을 멈춥니다. 트리에는 지금 실행 중인 명령이 노란색으로 표시됩니다.

  4. 4

    두 번째 반복

    count가 1일 때도 조건이 참이라 한 번 더 반복하고 `count: 2.0`이 표시됩니다.

  5. 5

    세 번째 반복

    count가 2일 때도 참이라 반복해 `count: 3.0`이 표시됩니다.

  6. 6

    실행이 끝났습니다

    count가 3이 되면 `count < 3`이 거짓이 되어 반복이 끝납니다. While 조건은 반복할 때마다 먼저 확인하므로 네 번째 반복은 실행되지 않습니다.

반복중단으로 반복 끝내기 ​

반복 안의 조건문(count == 2)에 반복중단을 넣어 반복을 도중에 끝내는 과정입니다.

  1. 조건문 안의 빈 영역을 눌러 위치를 정하고 편집 아이콘으로 명령어 목록을 연 뒤 반복중단을 추가합니다.
  2. 재생(▶)을 누르고 프로그램 변경 확인 창에서 저장을 누르면 프로그램이 실행됩니다.
  3. count: 1.0, count: 2.0이 표시된 뒤 count == 2가 참이라 반복이 끝나고, 세 번째 창은 나타나지 않습니다.

사용 방법 ​

  1. 1

    반복중단으로 반복 끝내기

    **반복중단**은 반복 안에서 실행하면 반복을 끝내고 반복 다음 명령으로 넘어가는 명령입니다. 보통 조건문 안에 넣어 특정 조건에서만 반복을 끝내게 합니다. 예제의 조건문 (If)에는 `count == 2` 조건이 들어 있으므로, 그 안의 빈 영역에 반복중단을 넣으면 count가 2가 될 때 반복이 끝납니다.

  2. 2

    조건문 안의 빈 영역 고르기

    조건문 (If) 아래의 빈 영역을 눌러 반복중단을 넣을 위치를 선택합니다.

  3. 3

    반복중단 고르기

    편집 아이콘으로 명령어 목록을 열고 공통 명령어의 반복중단을 누릅니다. 조건문 안에 반복중단이 추가됩니다.

  4. 4

    조건문 안의 반복중단

    조건문 (If) 안에 반복중단이 들어갑니다. `count`가 2가 되면 이 명령이 실행되어 반복이 끝납니다.

  5. 5

    프로그램 실행

    재생(▶) 버튼을 눌러 프로그램을 실행합니다. 프로그램을 바꾼 뒤이므로 저장 확인 창이 나타납니다.

  6. 6

    저장 후 실행

    프로그램을 바꾼 뒤 실행하면 **프로그램 변경 확인** 창이 나타나 저장 후 실행할지 묻습니다. **저장**을 누르면 저장하고 실행합니다.

  7. 7

    첫 번째 반복

    `count`가 1일 때는 If 조건(`count == 2`)이 거짓이라 반복이 계속되고 `count: 1.0`이 표시됩니다.

  8. 8

    count가 2일 때

    `count`가 2가 되면 `count: 2.0`이 표시됩니다. 이어서 조건문에서 `count == 2`가 참이라 반복중단이 실행됩니다.

  9. 9

    반복중단으로 끝났습니다

    세 번째 디버그 창은 나타나지 않고 프로그램이 끝납니다. While 조건(`count < 3`)이 아직 참이었지만 반복중단이 반복을 끝냈기 때문입니다.
