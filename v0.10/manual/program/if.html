조건문 (If) ​

조건문은 조건이 참인지 거짓인지에 따라 실행할 명령을 나누는 명령입니다. 예를 들어 "변수 count가 0이면 A 동작을, 아니면 B 동작을 실행"하는 프로그램을 만들 때 사용합니다.

이 문서에서는 프로그램 화면에서 다음을 해 봅니다.

  • 조건문 (If)을 추가하고 조건 입력하기
  • 조건문 (Else If)·조건문 (Else) 분기 더하기
  • 각 분기의 실행 결과 이해하기

준비

프로그램이 하나 열려 있어야 합니다. 프로그램이 없으면 새 프로그램 만들기를 먼저 따라 합니다.

조건문의 구성 ​

조건문은 하나 이상의 분기로 이루어집니다. 분기는 트리에서 같은 높이에 나란히 놓이며, 각 분기에는 조건이 참일 때 실행할 명령을 넣는 빈 영역이 함께 생깁니다.

분기트리 이름조건개수
If조건문 (If)필요합니다.처음 한 개
Else If조건문 (Else if)필요합니다.여러 개
Else조건문 (Else)없습니다. 앞의 조건이 모두 거짓일 때 실행합니다.한 개만

프로그램을 실행하면 위에서부터 조건을 차례로 확인해 처음으로 참인 분기 하나만 실행하고 나머지 분기는 건너뜁니다. 모든 조건이 거짓이면 Else 분기가 있을 때 그 분기를 실행합니다.

설정 화면 ​

조건문 (If)을 추가한 뒤 트리의 조건문 (If)을 누르면 오른쪽에 설정 화면이 열립니다. 조건을 입력하기 전의 화면입니다(① 칸에는 예로 count == 0을 입력해 두었습니다).

번호항목설명
①조건분기를 실행할 조건식을 입력합니다. 앞에서 선언한 변수를 쓸 수 있고 count == 0, count % 2 == 0처럼 참·거짓이 나오는 식을 적습니다. 비워 두면 저장할 수 없습니다. 입력칸을 누르면 화면 키보드가 나타납니다.
②조건문 (Else If) 추가앞의 조건이 거짓일 때 확인할 다른 조건 분기를 더합니다. 여러 번 추가할 수 있습니다.
③조건문 (Else) 추가앞의 조건이 모두 거짓일 때 실행할 분기를 더합니다. 이미 Else가 있으면 눌리지 않습니다.
④닫기설정 화면을 닫습니다. 저장하지 않은 변경이 있으면 저장하지 않고 닫을지 묻습니다.
⑤저장입력한 조건을 적용하고 설정 화면을 닫습니다. 트리의 조건문 옆에 조건이 표시됩니다.

② ③ 영역은 조건문 (If) 설정 화면에만 있습니다. Else If 분기의 설정 화면에는 조건 입력칸만 있고, Else 분기에는 조건이 없어 입력칸이 나타나지 않습니다.

추가하기 전에 저장하세요

② ③으로 분기를 더하면 설정 화면이 새 분기로 바뀝니다. 조건문 (If)에 입력한 조건은 저장해야 트리에 남으므로, 분기를 더하기 전에 ⑤ 저장을 먼저 누릅니다.

직접 해 보기 ​

예제 프로그램은 변수 count를 2로 두고, 조건문의 세 분기(If → Else If → Else)가 result를 각각 1·2·3으로 만든 뒤 디버그 명령으로 count와 result를 창에 보여 줍니다. 실습은 세 가지이며 어느 쪽부터 해도 되고, 앞의 실습을 하지 않아도 시작할 수 있습니다. 실습을 다시 시작하면 바꾼 값은 처음 상태로 돌아갑니다.

조건 설정하기 ​

If와 Else If에 조건을 입력하고 저장하는 과정입니다. 시작할 때 두 조건은 비어 있습니다.

  1. If의 설정 화면을 열어 조건에 count == 0을 입력하고 저장합니다. 입력한 값이 안내와 같아야 다음으로 넘어갈 수 있으며, 공백은 다르게 입력해도 같은 값으로 봅니다. 건너뛰면 자동으로 입력됩니다.
  2. Else If에도 조건 count > 0을 입력하고 저장합니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    예제 프로그램은 `count`를 2로 두고, 조건문의 세 분기(If → Else If → Else)가 `result`를 각각 1, 2, 3으로 만듭니다. If와 Else If의 조건은 아직 비어 있고, 마지막 디버그가 `count`와 `result`를 보여 줍니다.

  2. 2

    편집 아이콘 누르기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 편집 화면이 열립니다.

  3. 3

    조건문 (If) 선택

    트리에서 조건문 (If)을 누르면 선택됩니다.

  4. 4

    조건문 (If) 설정 화면 열기

    선택된 조건문 (If)을 한 번 더 누르면 설정 화면이 열립니다.

  5. 5

    조건문 설정 화면

    조건문 설정 화면은 두 영역으로 나뉩니다. 상태 설정에서 조건을 입력하고, 상태 추가에서 조건문 (Else If)·조건문 (Else) 분기를 추가합니다.

  6. 6

    If 조건 입력

    If의 조건에 분기를 실행할 조건을 입력합니다. 예에서는 `count == 0`을 입력합니다.

  7. 7

    저장

    저장을 누르면 If 조건이 적용됩니다.

  8. 8

    Else If 선택

    Else If 분기의 조건도 같은 방법으로 정합니다. 트리에서 조건문 (Else if)를 눌러 선택합니다.

  9. 9

    Else If 설정 화면 열기

    선택된 조건문 (Else if)를 한 번 더 누르면 설정 화면이 열립니다.

  10. 10

    Else If 조건 입력

    Else If의 조건을 입력합니다. 앞의 If 조건이 거짓일 때만 확인하며, 예에서는 `count > 0`을 입력합니다.

  11. 11

    저장

    저장을 누르면 Else If 조건이 적용됩니다.

분기 실행 확인하기 ​

조건이 이미 입력된 조건문(If: count == 0, Else If: count > 0)을 실행해 어느 분기가 실행되는지 확인하는 과정입니다.

  1. 재생(▶)을 누르면 프로그램이 실행됩니다.
  2. 조건문은 위에서부터 차례로 조건을 확인합니다. count == 0은 거짓이라 건너뛰고 count > 0이 참이라 Else If가 실행되어, 디버그 창에 count: 2.0, result: 2.0이 표시됩니다. Else는 실행되지 않습니다.
확인 순서조건결과(count가 2일 때)
1If: count == 0거짓이라 건너뜁니다.
2Else If: count > 0참이라 이 분기를 실행해 result = 2가 됩니다.
3Else앞에서 참인 분기가 있었으므로 실행하지 않습니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    프로그램 살펴보기

    예제 프로그램은 `count`를 2로 두고, 조건문의 세 분기가 `result`를 각각 1, 2, 3으로 만듭니다. If의 조건은 `count == 0`, Else If의 조건은 `count > 0`이며, 마지막 디버그가 `count`와 `result`를 보여 줍니다.

  2. 2

    프로그램 실행

    재생(▶) 버튼을 눌러 프로그램을 실행합니다.

  3. 3

    실행된 분기 확인

    디버그 창에 `count: 2.0`, `result: 2.0`이 표시됩니다. `count == 0`이 거짓이라 If 분기는 건너뛰고, 다음으로 확인한 `count > 0`이 참이라 Else If 분기가 실행되었습니다. 처음으로 참인 분기 하나만 실행하므로 Else 분기는 실행되지 않습니다. 트리에는 지금 실행 중인 명령이 노란색으로 표시됩니다.

조건을 바꿔 비교하기 ​

If 조건을 바꿔 실행하고 결과를 앞의 실행과 비교하는 과정입니다. 시작할 때 If는 count == 0, Else If는 count > 0입니다.

  1. If의 설정 화면을 열어 조건을 count == 2로 바꾸고 저장합니다.
  2. 재생(▶)을 누르고 프로그램 변경 확인 창에서 저장을 누르면 프로그램이 실행됩니다.
  3. count가 2라 If와 Else If가 모두 참이지만 처음으로 참인 분기 하나만 실행하므로 result: 1.0이 표시됩니다.
가상 로봇으로 직접 따라 해 보세요브라우저 안의 가상 로봇(C500920, SB5-920E)으로 실습하며, 실제 로봇은 움직이지 않습니다. 화면 구성과 조작 방법은 실제 UI와 같고, 안내에 따라 강조된 곳을 직접 눌러 보세요.지원 환경: 창 너비가 높이보다 큰 가로 화면, 너비 667px 이상 (PC·태블릿·휴대폰 가로 모드)각 실습은 앞의 실습을 하지 않아도 시작할 수 있고, 시작할 때마다 처음 상태에서 출발합니다.

사용 방법 ​

  1. 1

    조건을 바꿔 실행하기

    If 조건을 `count == 2`로 바꾸면 `count`가 2일 때 If와 Else If(`count > 0`)가 모두 참이 됩니다. 이때 어느 분기가 실행되는지 확인합니다.

  2. 2

    편집 아이콘 누르기

    트리 위쪽의 편집 아이콘을 누르면 오른쪽에 편집 화면이 열립니다.

  3. 3

    조건문 (If) 선택

    트리에서 조건문 (If)을 누르면 선택됩니다.

  4. 4

    조건문 (If) 설정 화면 열기

    선택된 조건문 (If)을 한 번 더 누르면 설정 화면이 열립니다.

  5. 5

    If 조건 바꾸기

    If의 조건을 `count == 2`로 바꿉니다. 입력칸 오른쪽의 ✕로 기존 값을 지운 뒤 입력합니다.

  6. 6

    저장

    저장을 누르면 바뀐 조건이 적용됩니다.

  7. 7

    프로그램 실행

    재생(▶) 버튼을 눌러 프로그램을 실행합니다. 프로그램을 바꾼 뒤이므로 저장 확인 창이 나타납니다.

  8. 8

    저장 후 실행

    프로그램을 바꾼 뒤 실행하면 **프로그램 변경 확인** 창이 나타나 저장 후 실행할지 묻습니다. **저장**을 누르면 저장하고 실행합니다.

  9. 9

    처음 참인 분기만 실행

    `result`가 1이 됩니다. `count`가 2라 If(`count == 2`)와 Else If(`count > 0`)가 모두 참이지만, 위에서부터 확인해 **처음으로 참인 분기 하나만** 실행하고 나머지는 건너뜁니다.

분기 안에 명령 넣기

각 분기 아래의 빈 영역을 누르고 편집 아이콘으로 명령어 목록을 열어 원하는 명령을 추가하면 그 분기가 선택됐을 때 실행됩니다.
